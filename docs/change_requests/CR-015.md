# CR-015：把“读出增强写入 + 预测误差门控”的工作记忆接入完整模块化网络（T-Gate）

**用户于 2026-10-29 批准本 CR。** 配套协议 `p6-protocol-v1`（`docs/p6_implementation_spec.md`，status: ACCEPTED）随本次提交冻结。此后的任何改动都必须走新的 CR 或勘误，不得直接编辑冻结的协议。

## 触发证据（T track，均为 exploratory，不构成 Gate 证据）

| 来源 | 结论 |
|---|---|
| T1（`docs/transfer/T1-report.md`） | 预测误差（结果 surprise）门控工作记忆写入：无提示规则切换后的恢复 +10.9pp，学会的 seed 从 5/10 增至 10/10；但仍比 shared GRU 差 2.9pp |
| T1b（`docs/transfer/T1b-report.md`） | 候选写入改为来自读出增强后的表示（读—改—写）并保留门控后，与 shared GRU 非劣（−0.3pp / −0.05pp），差距缩小 96–99%；写入结构决定上限，门控决定可靠性；二者缺一不可 |
| T1c（`docs/transfer/T1c-report.md`） | 三个情境交错、单情境静默切换时，T1b 的工作记忆比 GRU 恢复低 3.6pp、OOD 低 2.2pp（非劣不成立）；槽结构对未切换情境的干扰更小，但被切换情境的更新更差。事后推测：surprise 门控加在所有槽上，不按情境寻址 |
| T1d（`docs/transfer/T1d-report.md`） | 把 surprise 偏置按读出注意力分配到槽上：多情境恢复只比全局门控高 1.2pp（不显著），仍比 GRU 低 2.5pp；单情境无害。T1c 的事后推测不被支持 |
| T2（`docs/transfer/T2-report.md`） | 与本 CR 无直接关系（读出/防遗忘），但提示：主网络模块上的局部规则可以得到与回放相当的结果 |
| P5（CR-009） | 主线当前把预测 surprise 用作路由调制；T track 的结果提示它更应门控记忆写入 |

## 拟批准的变更

1. **新模块 `working_memory.v2`**（`neuromorphic.modules`，新模块 ID 与 state version `working-state-v2`；`working_memory.v1` 不改）：
   - 读出与 v1 相同：a_t = softmax(M_{t−1} q(r_t)/√d)，e_t = r_t + P·read_t；
   - 候选写入来自读出增强后的表示：c_t = tanh(W_c e_t + b)；
   - 更新门加入 detached 的预测误差：g_t = σ(W_g r_t + b + s_t·w)，w 每槽一个、初值 2.0；
   - 其余（4 个槽 × 32 维、read-before-write、episode reset、逐 item TBPTT）与 v1 相同。
2. **新组合器 `ModularBrainNetworkV4`**：在 V3 的图上把 `working_memory.v1` 换成 v2，并把 `predictive_adapter.v3` 已经计算的每步 surprise（P5 冻结的 detached `log1p` SmoothL1 forecast error）同时送入 v2 的更新门。路由与其他模块不变。
3. **主线任务新增 `uncued-rule-switch`**：把 T1 的无提示切换任务改写为主线任务接口（作答后有结果反馈、无切换 cue），与 AR、DRS、SmallGraph 一起构成四任务套件；全部使用新的 P6 namespace 与独立 split seeds（train 31101、validation 32201、test 33301、OOD 34401、analysis 35501），不复用 P1–P5 与 T track 的样本。
4. **新协议 `p6-protocol-v1` 与 Gate `GATE-6-WM`**，阶段与主线相同：qualification → pilot → mechanism → full，每一阶段通过只授权进入下一阶段。

## 保持项

- P1–P5 的模块、任务、配置、协议、锁与历史结果全部不变，`p5-protocol-v2` 不受影响。
- `neuromorphic.transfer` 与 `neuromorphic.fly` 不被主线导入；v2 在主线中按主线抽象重新实现，并用单元测试逐元素核对它与 T1b 的 `enr_gate` 方程一致。
- T track 结果只作为本 CR 的动机，不作为 `GATE-6-WM` 的证据。

## 用户决定（2026-10-29 审阅）

本节记录审阅结论，均已写入冻结的 `p6-protocol-v1`。

0. **T1d（已完成，用户决定先做）。** 按读出注意力寻址的门控（`docs/transfer/T1d-report.md`）没有可靠地改善多情境下的更新（+1.2pp，不显著），对单情境无害。按 T1d 协议的预设规则，`working_memory.v2` 保留 T1b 的全局门控，“多个独立变量时不如 GRU（约 −2.5pp）”列为已知缺陷。事后看，寻址在 7/10 个 seed 上追平 GRU、3/10 学得慢；若希望继续，可另立协议检验“寻址 + 更长预算”。
1. **底座：(b)，以 V3 为底座直接启动，不等 P5 mechanism。** 门控需要 `predictive_adapter.v3` 的 detached surprise；V2 的预测器把误差加回感觉表示，已在 P4 被否证，所以 (c) 不可行。V4 与 V3 只差工作记忆，mechanism 的对照都在同一底座上，v3 路由在 P5 中的成败不影响对工作记忆的因果裁决。
2. **surprise 来源：以预测器的 forecast error 为主。** 结果 surprise（|反馈 − 自己的作答概率|）需要在模块里写死反馈步与答案位，只对 uncued-rule-switch 有定义。qualification 加两项检查：(i) 反馈步上 forecast error 与结果 surprise 的 Spearman 相关 ≥ 0.5；(ii) 分别报告反馈步与非反馈步的 s_t 分布，因为 T1 的门权重初值 2.0 按 s ∈ [0, 1] 标定，而主线 surprise 是 `log1p` SmoothL1，尺度需要核对。任一项不满足即停止并回报，不在本协议内换来源。
3. **Gate 范围：主检验 = M1–M5 + F1。** F1 为 uncued-rule-switch 恢复准确率对 shared GRU 与 shared Transformer 非劣（界值 2pp）。四任务 ID/OOD 总分（F2、F3）降为次要检验，单独 Holm family，照常报告，但不决定 Gate。理由：P3 中模块化网络对 Transformer 已经落后（任务分 −8.6pp、OOD −4.0pp、AULC −13.5%，`reports/gates/GATE-NN-MVP.md`），这与工作记忆无关；本 Gate 只裁决本 CR 改动的模块。`GATE-6-WM` 通过不等于网络 MVP，不构成 `GATE-NN-MVP-v2` 证据，也不允许任何 MVP 表述。superiority（F4）仍是次要检验，因为 T1b 中 `enr_gate` 只与 GRU 持平（−0.3pp）。
4. **seed：五个，`[17, 29, 43, 59, 71]`。** 59 与 71 在主线中从未使用。T 线中工作记忆的学习是双峰的（无门控时约一半 seed 停在 0.54），T1d 也有 3/10 个 seed 学得慢；只有三个 seed 时，一个卡住的 seed 就足以翻转 M1–M4。M5 的“每个任务与 seed”规则沿用主线不变，检查项由 9 个增至 15 个。
5. **设备：Windows CUDA 通道**（与 P4/P5 相同）。mechanism 墙钟上限 48 小时，full 24 小时。参考：P4 的 24-cell CUDA mechanism 实际用时 11.2 小时。
6. **（审阅新增）pilot 网格加入 lr = 1e-3。** P5 的四个 preset 学习率只有 1e-4 与 3e-4，而 T1 的 `gate` 10/10、T1b 的 `enr_gate` 9/10 个 seed 都选中了 1e-3；只用 P5 网格可能让机制训练不足而产生假阴性。P6 pilot 网格为 P5 的 `preset-0`–`preset-3` 加 `preset-4`（lr 1e-3，其余同 `preset-1`）。
7. **（审阅新增）早停 patience 30。** validation 间隔仍为 100 次更新，patience 由 P5 的 10 提高到 30，即 3,000 次更新没有改善才停止。T1 的工作记忆变体在 3,000 次更新时仍在上升，T1d 的慢 seed 到 10,000 次仍在上升。

## 风险

- 预测器的 forecast error 在 AR/SmallGraph 上不是“结果”信号，门控可能在这些任务上无谓地打开写入；mechanism 设有逐任务非退化检查（≤ 2pp）。
- 工作记忆是路由的可选专家之一；若路由很少把反馈步送入工作记忆，门控就没有作用。qualification 中检查 uncued-rule-switch 的反馈步进入工作记忆的比例，协议已冻结语义覆盖：与 DRS 一样强制 100%。
- T1c 已显示多情境下工作记忆不如 GRU；主线的 AR（多对 key-value）与 SmallGraph 需要多个独立变量，四任务总分（F2、F3）可能不如基线。按决定 3，它们不决定 Gate，但必须如实报告。
- `preset-4` 的学习率比 P5 网格高约 3 倍，可能使其他任务训练不稳；pilot 沿用 P5 的 eligibility 规则，不合格的候选不参与排序。
