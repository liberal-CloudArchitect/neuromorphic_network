# CR-013：开设果蝇连接组探索支线（F track）

## 触发证据

P3、P4 与 P5 设计审计显示，预测假说连续失败的主要原因是任务与机制不匹配：AR/DRS 的下一观测不依赖动作，DRS 切换有显式 cue，SmallGraph 完全可观测，且 teacher-forced 训练使 `(s, a, s')` 错配。果蝇拥有完整公开连接组（FlyWire、BANC 等），其中蘑菇体、多巴胺区室与中央复合体具有功能较清楚的回路，可为每个机制提供“非它不可”的受控试验场。

## 批准范围

- 新增独立子包 `neuromorphic.fly`；不得被 P1～P5 主线、Gate 或锁链导入。
- 结果一律标记为 exploratory，不构成任何 `GATE-*` 证据，也不改变 `p5-protocol-v2`。
- 数据只放在 git-ignored 的 `data/fly/`；每个文件必须先列入 `docs/fly/dataset_inventory.md`，经人工批准后用带 size/checksum 的 manifest 获取。
- 不登录、不使用 token；需要登录或 token 的数据源由用户自行处理。
- 遵守各数据集许可与引用要求；项目仍为专有未发布状态，不再分发原始数据。

## F0 验收（管线与复现）

1. 数据完整性：所有已批准文件的 size 与 checksum 与 manifest 一致。
2. 加载复现：FlyWire 目标版本的神经元数、聚合边数与总突触数和发布统计一致（容差在 inventory 中冻结）。
3. 模拟复现：按上游默认参数的全脑 LIF 定性复现一个已发表结果（候选：Shiu et al. 2024 糖觉 GRN → MN9 激活），判据在运行前写入本 CR 的附录。
4. 可复现性：固定 seed 的 CPU 结果逐位一致；CPU/MPS 发放率在预先声明的容差内一致。

## 科学边界

- 连接组只给出突触数与推断的递质符号，不是突触效能、神经调质、缝隙连接或内在动力学的真值；全脑 LIF 只是定性模拟器，不是“果蝇大脑仿真”。
- 任何“真实拓扑更好”的主张必须同时对照保度重连零模型、细胞类型置乱和同密度随机稀疏图，且各模型从相同随机初始化开始训练。
- 果蝇回路提供算法原理，不得改称为海马、前额叶或其他哺乳动物脑区。

## 后续

F0 通过后，F1 依次开展蘑菇体持续学习、多巴胺门控 surprise 学习和中央复合体环形吸引子三项回路级研究；任何原理迁回主网络时必须经过新的 protocol 与 CR。

## 附录：F0 结果（2026-10-04）

F0 的 4 项验收全部完成，详见 `docs/fly/F0-report.md`。复现判据是在首轮诊断之后才写下的，因此只作为工程复现记录。实现中确定了一个语义：不应期内到达的突触输入被丢弃（`refractory_input="discard"`）。按这一语义，结果与上游 Brian2 参考输出的逐神经元放电率相关为 0.9998。

## 附录：F1 结果（2026-10-05）

F1 共 27 轮实验（含 3 轮因资格检查失败而判为 INVALID 的协议），每轮都在运行前冻结并提交协议，结果均为 exploratory，不构成任何 Gate 证据。逐轮结论见 `docs/fly/F1*-report.md`，综合结论与迁移建议见 `docs/fly/F1-summary.md`。

| 研究线 | 主要结论 | 证据 |
|---|---|---|
| 蘑菇体持续学习 | 局部关联读出（只增强活跃单元到正确输出、其余冻结）防遗忘，比 SGD 与感知机读出高 30–43pp；稀疏扩展码只在码可靠的多峰类别下优于原型学习；PN→KC 真实拓扑没有可利用的优势 | F1a v1–v4、F1d |
| 多巴胺门控学习 | 预测误差门控（DAN = r − v）在无提示反转下比纯关联学习高 20.5pp；全局 surprise 调制无额外收益 | F1b |
| MB 输出回路 | MBON→DAN 互惠反馈结构富集 7.3×；在本抽象中它不实现 RPE（F1h），无标签时造成整体效价漂移（F1j），加突触级资格标签后实现记忆特异巩固（F1k）；功能不依赖真实接线 | F1e、F1h、F1j、F1k |
| 中央复合体 | 真实拓扑支持提示特异的持续状态（FlyWire 与 hemibrain；hemibrain 需按类型统一递质符号）；视觉输入映射靠共激活可塑性习得（F1i）；路径积分在 hemibrain 上复现，PEN→EPG 偏移拓扑是因果成分（打乱取消转动、保留记忆；镜像使方向反转）；以积分为目标搜索时，真实接线约六成 seed 找到恒速、速度分级的积分器，零模型一个都没有（积分依赖真实拓扑与 PEN→EPG 拓扑），但积分器在参数空间中稀少，按均值门槛“稳定找到”未获支持 | F1c-v4、F1i、F1m、F1o、F1p、F1q、F1r、F1s |

方法学上，F1 确立了以下规则：阳性对照资格检查、参数匹配的比较、活动下限（平均活动与空间结构）、以新异刺激为参照的记忆指标、方向与反对称并列的转动指标、按细胞类型检查递质一致性，以及冻结前只在非正式 seed 上做冒烟测试并披露改动。

本 CR 的状态仍为 PROPOSED，是否改为批准由项目负责人决定。任何原理迁回主网络，仍需新的 protocol 与 CR。
