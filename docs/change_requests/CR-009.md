# CR-009：以预测 surprise 调制路由并稳定任务语义

## 触发证据

`GATE-4-MECH-CUDA` 完整执行后，预测质量通过但 retrained predictor-off 因果比较失败；DRS 路由在 seed 29 从 working memory 漂向 episodic，并突破 dense 非劣界限。v2 router 的单专家 masked softmax 在前向中权重恒为 1，主任务损失难以训练 scorer，load-balance 因而可能主导任意分工。

## 批准变更

- `predictive_adapter.v3` 将下一 latent 建模为 persistence 加有界 action-conditioned delta；最后一层零初始化，因此初始行为严格等于 persistence。
- 预测误差不再加回当前感觉表示。detached `log1p` surprise 只作为路由上下文，避免任务损失扭曲预测质量目标。
- `sparse_router.v3` 保留 AR store/query → episodic，并增加所有有效 DRS event → working 的强制覆盖。
- 每个 DRS step 最多 `floor(valid × 0.25)` rows 根据 score ambiguity 与 surprise 额外执行 episodic；其余为单专家。
- fusion 使用 hard-forward/soft-backward straight-through 权重，使主任务损失可以训练 scorer；语义 token 另加 observation-derived cross-entropy，不读取 target 或未来状态。
- 新增独立 P5 task namespace 与 split seeds `21101/22201/23301/24401/25501`，不得复用 P4 test/OOD 进行选择。

## 保持项

P1–P4 模块、checkpoint 与历史结果保持可加载；P4 失败裁决不可追溯修改。v3 仍使用 read-before-write、episode reset、逐 item TBPTT、显式 device 和无 atlas/Web/3D 依赖。
