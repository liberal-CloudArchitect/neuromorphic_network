# CR-011：冻结 P5 三种子 mechanism 与 Gate

## 矩阵

正式 seeds 固定 `[17,29,43]`，每 seed 八个 cells，共 24：

重新训练：`full`、`predictor-off`、`surprise-off`、`no-dual-route`。

同 seed full checkpoint 控制：`acute-surprise-off`、`shuffle-surprise`、`dense-memory`、`no-semantic-reservation`。

CPU/CUDA mechanism qualification 使用 seed 7 的相同 8-cell 镜像，每个 retrained cell 每任务 2 updates；它只验证执行、恢复、逐样本记录与统计路径，不参与正式结论。

## 正式预算

- P5 namespace；train/validation/analysis/test `8192/2048/512/2048`；不在 mechanism 中访问 OOD。
- batch 64，每个 retrained cell 每任务最多 5,000 updates；每 100 updates validation/checkpoint，patience 10，48 小时累计墙钟。
- optimizer 必须来自同 SHA pilot lock；当前选择为 `preset-1`。
- 10,000 次 paired hierarchical bootstrap，RNG `20260715`，95% CI，五项 Holm family。

## Gate

- full 相对 retrained surprise-off 与 predictor-off 的 macro AULC 分别相对提高至少 5%，CI 下界 >0、Holm p≤0.05，且任一 task/seed 最终分数下降不超过 2pp。
- full 相对 retrained no-dual-route 的 DRS 分数相对提高至少 3%，CI 下界 >0、Holm p≤0.05。
- 三任务每个 seed 的 forecast error 相对 persistence 至少降低 5%，family CI/p 通过。
- sparse 相对 dense 使用 `full + 2pp` margin bootstrap；CI 下界 >0、Holm p≤0.05，且任一 task/seed 原始下降不超过 2pp。
- optional active MAC 至少减少 20%；AR episodic 与 DRS working 语义覆盖 100%；dual fraction ≤25%；capacity drops=0。

任何 cell 缺失、资源超限、非有限值、锁/checksum 不匹配均不得生成 mechanism lock。Gate 失败必须提交负结果，不在同协议内换 seed、阈值或候选。
