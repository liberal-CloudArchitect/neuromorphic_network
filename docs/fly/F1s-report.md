# F1s 结果：积分器只在真实接线中被找到，并依赖 PEN→EPG 拓扑；但在参数空间里很稀少，按均值门槛“稳定找到”未获支持

本报告属于探索层，不构成 Gate 证据。协议在运行之前已冻结并提交（`c8e80d8`）；冻结前只在 seed 991 上运行过理想环对照。

`lno` 的两道门都通过；`pen` 的 `shuffled` 门未通过：在直接 PEN 驱动下，打乱后的理想环也能得到高分（持续性截断在 2.00，即**加速**的转动，而不是恒速）。按协议，S6 判为 INVALID。这说明直接 PEN 驱动可以在没有偏移拓扑的情况下制造出“伪积分”（seed 991 的设计检查中则没有出现）。

## 3. 解释

1. **积分依赖真实拓扑，并具体依赖 PEN→EPG 拓扑**（S2、S3）。在 LNO 驱动下，真实接线有 6/10 个 seed 找到了积分器（持续性 0.5–1.5、分级性 ≥ 1 rad/s 的满分区间附近，s(t) 线性 R² 平均 0.91）；三种零模型在 10 个 seed 中**一个都没有**（R² 0.43–0.69）。
2. **但积分器在参数空间中很稀少。** 搜索中 I ≥ 0.5 的候选只占约 0.1%（1,000 组中约 1 组）；均值 0.478 刚好低于预注册的 0.5（S1），即“只调类型参数、1,000 组随机候选”的预算下，不能稳定地找到积分器。与 F1r 相比，以积分为目标把积分器的比例从 4/10 提高到 6/10。
3. **直接 PEN 驱动不是可靠的检验方式**：真实接线只在 3/10 个 seed 中找到积分器（其中 1 个是加速型），而且在理想环上，打乱后的 PEN 驱动也能产生加速的“伪积分”。生物学上的速度输入是 LNO（对侧抑制），LNO 驱动下的结论更可信。

## 4. 结论

- 路径积分这一条线的最终表述：**真实 hemibrain CX 接线能够实现恒速、速度分级的角度积分，零模型不能；这种能力依赖 PEN→EPG 的偏移拓扑（F1q、F1s）。但在统一类型参数的抽象中，积分器只占参数空间很小的一部分，用 1,000 组随机候选只能在约六成的 seed 中找到。**
- 方法学：持续性得分把 P 截断到 [0, 1]，会把加速转动（P = 2）也算作满分；今后的积分得分应惩罚 |P − 1|，而不是只截断上限。
