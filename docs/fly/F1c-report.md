# F1c 结果：结构上是环，均匀参数动力学上不是吸引子

本报告属于探索层，不构成 Gate 证据。协议在实现和运行之前已冻结并提交（`107e747`）。

## 1. 结构（描述性）

| 图 | 谱特征值 λ₁ / λ₂ / λ₃ | 环性判断 |
|---|---|---|
| real | 0.215 / 0.242 / 0.445 | λ₁、λ₂ 近似简并且与 λ₃ 明显分开，**是环** |
| type_preserving（10 次实现的均值） | 0.690 / 0.721 / 0.740 | 不分开，无环 |
| degree_preserving（10 次实现的均值） | 0.663 / 0.696 / 0.715 | 不分开，无环 |

只用连接组就能恢复中央复合体的角度拓扑。保持类型级统计、只打乱个体连接（`type_preserving`）就足以抹掉环结构，所以环结构存在于个体层面的精确接线中，而不在类型级统计里。

## 2. 动力学（预注册）

各图按协议分别标定参数：real 选中 g = 2.0、b = 0.1；零模型选中的值随实现不同而变化。

| 图 | 8 选 1 记忆准确率（机会 0.125） | 延迟期与提示期活动的相关 |
|---|---:|---:|
| real | 0.124 | 0.951 |
| type_preserving | 0.172 | 0.608 |
| degree_preserving | 0.115 | 0.699 |

| ID | 比较 | 均值 Δ | 95% CI | 裁决 |
|---|---|---:|---|---|
| J1 | real − 0.5 | −37.6pp | [−40.1, −35.0] | NOT_SUPPORTED |
| J2 | real − type_preserving | −4.9pp | [−7.5, −2.3] | NOT_SUPPORTED |
| J3 | real − degree_preserving | +0.9pp | [−1.8, +3.4] | NOT_SUPPORTED |

## 3. 解释

- real 图的延迟期活动与提示期活动高度相关（0.951），但不能区分提示（准确率等于机会水平）。也就是说，网络落入了**单一的全局吸引子**，不管提示在哪里，都会收敛到同一个活动模式，而不是形成随提示位置不同的“bump”。
- 在本协议的模型类中，“全局增益、全局偏置、突触数即权重”的速率动力学**不足以**让真实接线表现出环形吸引子。这否证的是这一抽象，不是真实拓扑本身的作用：第 1 节已经表明，环结构确实只存在于真实接线中。
- 已知的环形吸引子模型依赖细胞类型特定的参数，例如 Delta7 的抑制强度、PEN 与 EPG 的增益比、环神经元（ER）提供的全局抑制。Lappalainen et al. 2024 在视觉系统中也采用“连接组固定、训练细胞类型参数”的做法。

## 4. 下一步

**F1c-v2：** 连接组拓扑固定，只训练少量细胞类型参数（每种类型的增益与偏置，共约 12 个），用 BPTT 在提示记忆任务上优化。真实图和每个零模型都使用完全相同的训练预算，并在新的 seeds 上用与本协议相同的模板解码评估。这样检验的是：在最优的类型级参数下，真实拓扑能否支持记忆，而零模型不能。
