# F1j 结果：真实 MBON→DAN 正反馈不巩固单个记忆，而是让所有气味一起偏向趋近

本报告属于探索层，不构成 Gate 证据。协议在正式运行之前已冻结并提交（`f2220f7`）；冻结前只用非正式的 seed 996 做过冒烟测试，由此作出的设计改动已在协议第 2 节披露。

## 1. 资格检查与运行

- 资格检查通过（seeds 990–994）：`replay_oracle` − `none` 的趋近记忆指数为 +0.073（门槛 0.02）。说明这项任务与以新异气味为参照的指标能检测到巩固。
- 正式 seeds 150–159；全部变体共用同一个 12 点网格，主指标为网格平均；运行耗时 1,425 s。

## 3. 描述性结果

- **漂移不需要再暴露：** 在 `retention_novel`（第二阶段全是新异气味）中，`loop_real` 的偏向为 +0.057，与 `retention` 的 +0.055 几乎相同；趋近指数同样下降（0.011，`none` 为 0.058）。也就是说，漂移由任何气味的呈现驱动，而不是由训练记忆的再激活驱动。
- **获得阶段已受损：** 获得刚结束时，`loop_real` 的趋近指数就已经低于 `none`（0.094 对 0.119），厌恶指数也是（0.103 对 0.134）。反馈在强化期间就把一部分教学信号分散到了与当前气味无关的方向上。
- **反转：** 原为趋近的气味，在 `loop_real` 中反转得较少（0.044，`none` 为 0.064），但 `loop_rewired`（0.046）与 `loop_flipped`（0.045）同样如此，而且三者获得阶段的记忆本来就更弱。这个代价不是真实接线特有的。
- **`ideal`（RPE）** 在无强化的再暴露下出现消退（趋近指数从 0.117 降到 0.017），这符合 RPE 的预期，在“环境没有改变”的保持任务里却是代价。
- **`loop_positive`**（纯同 compartment 正反馈）把趋近与厌恶两类记忆一起抹平（都约为 0.01）：双侧对称的正反馈让回避 MBON 与趋近 MBON 都被压低，决策值随之互相抵消。

## 4. 结论

1. **特异巩固假设被否证（J1 方向相反）。** 在“compartment 级 DAN 教学信号 + 重叠的 KC 编码 + 只有压低的可塑性”这一抽象中，真实 MBON→DAN 反馈不会让单个记忆在无强化下自我维持。冒烟测试中的诊断给出了原因：反馈驱动几乎不区分训练气味与新异气味，所以被放大的是所有气味共有的成分。
2. **共模漂移得到支持（J2、J3）。** 真实反馈让整个效价状态偏向趋近：25% 的新异气味被判为“趋近”。符号取反后，漂移方向也随之反转（偏向厌恶）。漂移依赖反馈的**符号结构**：回避侧是去抑制的正反馈，趋近侧是被 relu 截断的负反馈。
3. **但漂移不依赖真实接线的特异性（J4）。** 保度重连的反馈漂移得更强。F1e 发现的互惠富集（7.3×）仍然没有找到功能解释。
4. 与 F1h 合起来看：在本抽象中，真实 MBON→DAN 回路既不实现 RPE，也不实现记忆特异的巩固，它的可测作用是给整个系统加一个依赖符号的**效价偏置**。要让反馈承担记忆特异的功能，教学信号至少需要与气味身份绑定的成分，例如 KC 侧的资格迹（eligibility trace）、更低的码重叠，或者按 compartment 分开的、彼此不对称的阈值。这些都没有在本协议中检验。

## 5. 对类脑设计的启示

- 全局（或模块级）的调制信号如果经由正反馈回路自我放大，改变的是系统的**整体状态或偏好**，而不是单条记忆。这类回路适合实现“状态/情绪”式的偏置，不适合实现记忆巩固。
- 想要记忆特异的巩固，就需要特异性：要么调制信号本身携带“是哪条记忆”的信息（`replay_oracle` 证明这样有效，相当于离线重放），要么可塑性由局部资格迹门控。这与主线中“重放 + 局部门控写入”的设计方向一致。
