# F1 阶段总结

F1 共进行了 19 轮实验：F1a 的 v1–v4、F1b、F1c 的 v1–v4、F1d、F1e、F1f 的 v1–v2、F1g 的 v1–v2、F1h、F1i 与 F1j。每一轮都在运行前冻结并提交协议，结果按协议裁决，事后分析另作标注。除 F1f 有意沿用 F1c-v4 已拟合的模型（评估噪声另取）外，各轮使用互不重叠的 seeds。所有结论都只适用于人工抽象，不构成 Gate 证据，也不代表果蝇的真实生理机制。

## 1. 已获支持的原理（可迁回主线的候选）

| 原理 | 证据 | 效应 |
|---|---|---|
| **局部关联读出 + 部分冻结防遗忘**：只增强“活跃单元 → 正确输出”的突触，其余冻结 | F1a 的 C1，F1a-v3 的 E3、E4 | 比 SGD、感知机读出高 30–43pp；遗忘从 0.54–0.90 降到 0.15 左右 |
| **稀疏高维扩展码适合多峰类别**（需要码可靠） | F1a-v4 的 G1、G2、G3（确认实验） | 比类均值原型高 17pp；5% 稀疏优于 50%（+2.8pp）；固定大小的读出接近需要保存全部样本的 1-NN |
| **预测误差门控可塑性适应无提示变化**（DAN = r − v） | F1b 的 H1 | 比纯关联学习高 20.5pp；稳定日程下也高约 21pp |
| **二值连接优于按突触数加权** | F1a–F1d 全部实验（描述性结果一致） | 突触数分布是重尾的，少数强输入主导 KC 的选择 |
| **精确拓扑支持环形吸引子式工作记忆**：只调细胞类型参数，真实 CX 接线即可在延迟期维持提示特异的状态 | F1c-v4 的 P1–P3 | real 0.659；比 type_preserving 高 38pp，比 degree_preserving 高 24pp |
| **输入映射靠可塑性习得，保持靠精确拓扑**：ER→EPG 共激活压低把宽调谐的解剖连接变成视觉朝向映射，学到的提示只在真实 CX 接线中保持 | F1i 的 I1、I2 | 学习映射比解剖映射记忆高 26.8pp（0.465 对 0.197）；比 type_preserving 高 26.4pp |
| **MB 输出端存在 compartment 特异的互惠回路**（结构）：MBON 优先反馈到教导自己的 DAN | F1e 的 O1（纯结构） | 互惠反馈比例 35.5%，零模型为 4.9%（7.3×）；PPL1 达 55%。功能未定：F1h 显示它不实现减法式 RPE，F1j 显示它也不实现记忆特异的巩固 |
| **经正反馈自我放大的调制信号改变整体效价状态，而非单条记忆**（功能，非接线特异） | F1j 的 J2、J3（J4 不支持） | 真实反馈符号让新异气味的平均 v 偏向趋近 +0.098（25% 被判为趋近），符号取反则偏向回避；保度重连的反馈漂移更强 |

## 2. 被否证或未获支持的设想

| 设想 | 证据 |
|---|---|
| 单峰类别下稀疏码优于原型学习 | F1a 的 C3、C5；F1a-v2 的 D1–D5 |
| “码塌缩”是稀疏码失效的原因 | F1a-v2 的 D1：归一化降低了重叠，但准确率只升 1.4pp |
| 全局 surprise 调制学习率在波动环境中带来额外收益 | F1b 的 H2：−1.6pp |
| 嗅小球采样偏好帮助判别真实气味 | F1d 的 L1、L2：效应约为 0 |
| 均匀参数速率模型能让真实 CX 接线表现出环形吸引子 | F1c 的 J1–J3 |
| 互惠的 MBON→DAN 反馈以抑制为主（即用减法实现 r − v） | F1e 的 O2：+21pp，p = 0.13，不显著 |
| 只按记忆选出的 CX 参数会自发产生路径积分 | F1f 的 R1–R3 |
| 真实 CX 核心在类型参数抽象下能同时记忆并左右相反地转动 | F1f-v2 的 S1–S3（阳性对照通过，real 找不到联合解） |
| 经真实 ER 视觉通路的提示能印刻出定位的朝向 bump | F1g-v2：三张图的记忆搜索最好都只有约 0.33；ER 多为宽调谐，生物上靠 ER→EPG 可塑性建立映射 |
| 真实 MBON→DAN 反馈实现 compartment 级 RPE | F1h：按字面支持的 W1/W2 来自标定区间混杂；参数匹配时真实回路不优于重连回路，慢区间更差；回避 MBON 抑制自己的 PAM，构成正反馈 |
| 正反馈 MBON→DAN 回路在无强化再暴露时巩固单条记忆 | F1j 的 J1：方向相反（−0.038）；连理想的同 compartment 正反馈也不巩固；重放预言机则能（+0.064） |
| 学习视觉映射或直接 EPG 提示后，真实 CX 在 LNO 驱动下左右相反地转动 | F1i 的 I3、I4；I5 按字面通过，但真实图的转动量中位数只有 0.02–0.04 弧度（阳性对照 0.42–0.81），不构成转动 |

## 3. 结构层面的发现

- **中央复合体的环结构只存在于真实的个体级接线中：** 谱间隙为 0.215/0.242 对 0.445，在两种零模型中都消失。蘑菇体的 PN→KC 连接则基本没有可利用的拓扑结构，真实接线与各零模型的差距都在 ±1pp 左右（真实气味下）。
- 结论：**“真实拓扑是否重要”取决于回路。** 环形吸引子类回路依赖精确拓扑，扩展编码类回路主要依赖统计量（入度、稀疏度、二值性）。

## 4. 方法学教训

1. 合成任务很容易“没有给机制留位置”，例如单峰类别下 NCM 几乎最优。这与主线 P3–P5 的失败原因相同。每个机制都需要一个“非它不可”的任务。
2. 结果对噪声区间很敏感（F1a-v3 → v4）：同类样本 KC 码的 Jaccard 重叠可以作为“码是否可靠”的诊断量。
3. 训练类参数时必须先做“不退化”资格检查（F1c-v2 的全网静默失败）。
4. 连接组模拟的实现语义会实质性改变结果（F0：不应期内的输入是否丢弃，影响约 20%）。

## 5. 对主网络的具体建议（需要新 protocol 与 CR）

1. **情景记忆模块：** 改为“二值随机稀疏扩展（约 5% k-WTA）+ 局部关联写入”，并在多实例或多峰类别、类增量任务上检验抗遗忘与容量。
2. **预测模块：** 把预测误差用作写入或学习门控，在**无提示**的规则或价值切换任务上检验（例如去掉 cue 的 DRS），不再用它修正表示或调制路由。
3. **工作记忆：** 连续变量（如朝向、规则相位）可以用“环形拓扑 + 少量类型参数”的吸引子模块来保持（F1c-v4）。参数应通过无梯度搜索或分阶段方法获得，而不是直接用长延迟的 BPTT。外部输入到吸引子的映射不要手工固定，而是用局部共激活可塑性学习（F1i：同样的输入，学习后记忆从 0.197 升到 0.465）。

## 6. 方法学补充

- F1c-v2 与 F1c-v3 都因为 BPTT 无法穿过 1,000 ms 的延迟期而失效。v3 的阳性对照资格检查及时拦截，没有产生误导性的零结果。事后用阳性对照做网格诊断，证明问题出在优化器而不是模型类。教训：**凡是训练类参数的协议，都必须先让阳性对照通过资格检查。**

- F1h：在共同网格、日程平均目标下分别调参，可能让各变体落入不同的工作区间（快学快忘 vs 慢学稳定），使预注册比较按字面通过却不反映结构作用。**今后的协议应同时预注册参数匹配的比较。**
- F1g：给阳性对照设定参数时，必须检查它在所有实验条件（包括二值阈值）下仍然成立。
- F1i：反对称指数 A 对位移幅度做了归一化，噪声级位移也能得到高 A。转动类指标必须同时要求位移幅度。
- F1j：记忆指标应以“从未强化的刺激”为参照，否则全局偏向会被当成记忆；冻结前在非正式 seed 上做冒烟测试，可以在不消耗正式 seeds 的前提下发现这类设计缺陷（改动需在协议中披露）。

## 7. 未完成项与下一步候选

- 路径积分（F1f、F1f-v2、F1g-v2、F1i 四轮未复现）：提示通路、权重形式、速度通路都已排除，剩下最可疑的是角坐标。谱嵌入把 PEN 的 ±1 个 PB 小球偏移压缩成 3–6°。下一步需要 PB 小球或 EB 楔区的解剖标注（例如 hemibrain 的 instance 名称）来定义角度与偏移；FlyWire 注释表里没有这些标签。
- MBON→DAN 回路：在本抽象中既不是 RPE，也不是特异巩固，而是依赖符号的效价偏置；互惠富集（7.3×）的功能仍未解释。可能还需要的成分有：KC 侧的资格迹、受体依赖的符号（谷氨酸经 NMDA 受体起兴奋作用）、DAN 的自发活动与阈值。
- 把 §5 的三项原理迁回主网络（各需要新的 protocol 与 CR）。F1i 与 F1j 补充两点：输入映射用局部可塑性学习、由固定拓扑保持（对应主线的“可塑输入层 + 固定吸引子”）；巩固用“携带记忆身份的重放”实现，而不是全局正反馈。
