# F1 阶段总结

F1 共进行了 25 轮实验：F1a 的 v1–v4、F1b、F1c 的 v1–v4、F1d、F1e、F1f 的 v1–v2、F1g 的 v1–v2、F1h、F1i、F1j、F1k、F1l、F1m、F1n、F1o、F1p 与 F1q。每一轮都在运行前冻结并提交协议，结果按协议裁决，事后分析另作标注。除 F1f 有意沿用 F1c-v4 已拟合的模型（评估噪声另取）外，各轮使用互不重叠的 seeds。所有结论都只适用于人工抽象，不构成 Gate 证据，也不代表果蝇的真实生理机制。

## 1. 已获支持的原理（可迁回主线的候选）

| 原理 | 证据 | 效应 |
|---|---|---|
| **局部关联读出 + 部分冻结防遗忘**：只增强“活跃单元 → 正确输出”的突触，其余冻结 | F1a 的 C1，F1a-v3 的 E3、E4 | 比 SGD、感知机读出高 30–43pp；遗忘从 0.54–0.90 降到 0.15 左右 |
| **稀疏高维扩展码适合多峰类别**（需要码可靠） | F1a-v4 的 G1、G2、G3（确认实验） | 比类均值原型高 17pp；5% 稀疏优于 50%（+2.8pp）；固定大小的读出接近需要保存全部样本的 1-NN |
| **预测误差门控可塑性适应无提示变化**（DAN = r − v） | F1b 的 H1 | 比纯关联学习高 20.5pp；稳定日程下也高约 21pp |
| **二值连接优于按突触数加权** | F1a–F1d 全部实验（描述性结果一致） | 突触数分布是重尾的，少数强输入主导 KC 的选择 |
| **精确拓扑支持环形吸引子式工作记忆**：只调细胞类型参数，真实 CX 接线即可在延迟期维持提示特异的状态（**两个连接组都成立，前提是递质符号按细胞类型统一**） | F1c-v4 的 P1–P3；F1i 的 I2；F1m 的 M1、M2；F1o 的 O1–O3 | 加活动下限后，FlyWire 上 real 比 type_preserving 高 41pp（突触数）与 28pp（二值）；hemibrain 按类型统一符号后高 63pp（0.961 对 0.334）与 31pp。先前 hemibrain 上的“不成立”（F1l、F1m）来自错误的递质标签 |
| **真实 CX 接线支持路径积分，PEN→EPG 偏移拓扑是因果成分**（hemibrain，递质符号按类型统一）：保持朝向的同时，单侧 LNO 或 PEN 驱动让 bump 左右相反地转动；只打乱 PEN→EPG 会取消转动但保留记忆，镜像偏移会让方向反转 | F1p 的 Q1、Q3、Q4；F1q 的 R1、R3、R4、R6、R7 | 联合得分约 0.62–0.74（type_preserving 约 0.1）；打乱 PEN→EPG 后 J 降到 0.10–0.25 而记忆仍为 0.91；镜像后方向反转（8/10、9/10）；LNO 下方向与结构预测一致（9/10） |
| **输入映射靠可塑性习得，保持靠精确拓扑**：ER→EPG 共激活压低把宽调谐的解剖连接变成视觉朝向映射，学到的提示只在真实 CX 接线中保持 | F1i 的 I1、I2 | 学习映射比解剖映射记忆高 26.8pp（0.465 对 0.197）；比 type_preserving 高 26.4pp |
| **MB 输出端存在 compartment 特异的互惠回路**（结构）：MBON 优先反馈到教导自己的 DAN | F1e 的 O1（纯结构） | 互惠反馈比例 35.5%，零模型为 4.9%（7.3×）；PPL1 达 55%。功能未定：F1h 显示它不实现减法式 RPE，F1j 显示它也不实现记忆特异的巩固 |
| **广播式调制 + 突触级资格标签 = 记忆特异的巩固**：非特异的反馈驱动只作用于强化时被打上标签的突触 | F1k 的 K1、K2（24/24 网格点；K3 不支持，非接线特异） | 标签回路的趋近记忆比无反馈高 2.3 个指数点（约为理想重放效果的 40%），并消除了共模漂移（偏向 +0.055 → −0.013） |
| **经正反馈自我放大的调制信号改变整体效价状态，而非单条记忆**（功能，非接线特异） | F1j 的 J2、J3（J4 不支持） | 真实反馈符号让新异气味的平均 v 偏向趋近 +0.098（25% 被判为趋近），符号取反则偏向回避；保度重连的反馈漂移更强 |

| 均匀参数速率模型能让真实 CX 接线表现出环形吸引子 | F1c 的 J1–J3 |
| 互惠的 MBON→DAN 反馈以抑制为主（即用减法实现 r − v） | F1e 的 O2：+21pp，p = 0.13，不显著 |

## 3. 结构层面的发现

- **中央复合体的环结构只存在于真实的个体级接线中：** 谱间隙为 0.215/0.242 对 0.445，在两种零模型中都消失。蘑菇体的 PN→KC 连接则基本没有可利用的拓扑结构，真实接线与各零模型的差距都在 ±1pp 左右（真实气味下）。
- 结论：**“真实拓扑是否重要”取决于回路。** 环形吸引子类回路依赖精确拓扑，扩展编码类回路主要依赖统计量（入度、稀疏度、二值性）。

## 4. 方法学教训

1. 合成任务很容易“没有给机制留位置”，例如单峰类别下 NCM 几乎最优。这与主线 P3–P5 的失败原因相同。每个机制都需要一个“非它不可”的任务。
2. 结果对噪声区间很敏感（F1a-v3 → v4）：同类样本 KC 码的 Jaccard 重叠可以作为“码是否可靠”的诊断量。
3. 训练类参数时必须先做“不退化”资格检查（F1c-v2 的全网静默失败）。
4. 连接组模拟的实现语义会实质性改变结果（F0：不应期内的输入是否丢弃，影响约 20%）。

## 5. 对主网络的具体建议（需要新 protocol 与 CR）

1. **情景记忆模块：** 改为“二值随机稀疏扩展（约 5% k-WTA）+ 局部关联写入”，并在多实例或多峰类别、类增量任务上检验抗遗忘与容量。
2. **预测模块：** 把预测误差用作写入或学习门控，在**无提示**的规则或价值切换任务上检验（例如去掉 cue 的 DRS），不再用它修正表示或调制路由。
3. **工作记忆：** 连续变量（如朝向、规则相位）可以用“环形拓扑 + 少量类型参数”的吸引子模块来保持（F1c-v4；F1m、F1o 在两个连接组上都确认了真实拓扑的优势）。参数应通过无梯度搜索或分阶段方法获得（并加活动下限），而不是直接用长延迟的 BPTT。外部输入到吸引子的映射不要手工固定，而是用局部共激活可塑性学习（F1i：同样的输入，学习后记忆从 0.197 升到 0.465）。

## 6. 方法学补充

- F1c-v2 与 F1c-v3 都因为 BPTT 无法穿过 1,000 ms 的延迟期而失效。v3 的阳性对照资格检查及时拦截，没有产生误导性的零结果。事后用阳性对照做网格诊断，证明问题出在优化器而不是模型类。教训：**凡是训练类参数的协议，都必须先让阳性对照通过资格检查。**

- F1h：在共同网格、日程平均目标下分别调参，可能让各变体落入不同的工作区间（快学快忘 vs 慢学稳定），使预注册比较按字面通过却不反映结构作用。**今后的协议应同时预注册参数匹配的比较。**
- F1g：给阳性对照设定参数时，必须检查它在所有实验条件（包括二值阈值）下仍然成立。
- F1i：反对称指数 A 对位移幅度做了归一化，噪声级位移也能得到高 A。转动类指标必须同时要求位移幅度。
- F1j：记忆指标应以“从未强化的刺激”为参照，否则全局偏向会被当成记忆；冻结前在非正式 seed 上做冒烟测试，可以在不消耗正式 seeds 的前提下发现这类设计缺陷（改动需在协议中披露）。
- F1l：随机搜索在 1,000 组候选中取带噪得分的最大值，会偏爱**静默网络**（对近零活动解码只得到噪声，方差大，容易成为最大值）。F1l 中 real 的联合最优参数有 6/10 是静默的。凡是搜索类协议，都必须加入活动下限，并对选中解用独立噪声重评估。F1c-v4 的选中参数全部活跃，不受影响。
- F1l：结构预测的门槛要留余量。S2 的方向与一致性都符合，只因为 PEN_a 左侧 69.5° 超出 67.5° 上限而判为未通过，连带让 P3 失效。
- F1q：消融要在正确的坐标里做（PB 标签相位与 EB 位置之间存在半格交错）；只看反对称会漏掉方向反转，方向指标应与反对称一起作为主指标。
- F1p：预测转动方向前，先核对输入通路的侧别（LNO→PEN 是严格对侧的，协议中写反了）；消融不能简单取整到相位步长；转动类指标应同时报告方向。
- F1n/F1o：用递质预测定符号前，先按细胞类型检查一致性。hemibrain 逐 body 预测把 38/46 个 EPG、一半的 PEN 标成谷氨酸，让三轮实验（F1l、F1m、F1n）都把一个注释问题误当成接线或组成的差异；直到检查 bump 落点分布（全部落在同一位置）才找到原因。跨数据集结果不一致时，应先排查递质、类型、侧别等注释。
- F1m：活动下限必须同时限制平均活动与空间结构。设计检查中，一个完全饱和的候选（活动 0.99999994，空间标准差 6×10⁻⁸）在搜索噪声下得分 1.0，换一个评估噪声就跌到机会水平。跨数据集比较二值图时，还要按边数匹配阈值：hemibrain 的突触数中位数是 FlyWire 的 2.7 倍，同一个 ≥ 5 阈值会让它的图密 2.3 倍。

## 7. 未完成项与下一步候选

- 路径积分：已在 hemibrain 上复现（F1p），并完成因果检验（F1q）。未做：转速与驱动强度的定量关系（积分精度）；在 FlyWire 上重做（需要先建立 FlyWire 与 hemibrain 神经元的对应关系，以获得 PB 小球标签）。
- CX 记忆优势的跨数据集稳健性：已解决。F1n 排除了类型级输入组成；事后诊断与 F1o 证实，hemibrain 上的“不成立”来自逐 body 递质预测把大多数 EPG/PEN/PEG 标成谷氨酸。按细胞类型统一符号后，两个连接组上都成立。
- MBON→DAN 回路：标签让它能做特异巩固（F1k），但这种作用不依赖真实接线；F1e 的互惠富集（7.3×）在 F1h、F1j、F1k 的三种功能检验中都没有找到必要性。DAN 的自发活动、经 DAN 活动下降实现的消退，以及跨 compartment 的协调都还没有检验。
- 把 §5 的原理迁回主网络（各需要新的 protocol 与 CR）。F1i–F1k 补充三点：输入映射用局部可塑性学习、由固定拓扑保持；巩固用“广播调制 + 突触级资格标签”（或携带记忆身份的重放）实现；避免没有门控的全局正反馈。F1o–F1q 再补充一点：保持状态（记忆）与更新状态（积分）可以由同一环上的不同连接块分别承担：环内回路负责保持，带偏移的旁路投射负责按速度移动状态。
