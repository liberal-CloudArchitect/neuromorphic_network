## 3. 解释

### 3.1 可塑性让视觉提示可用，真实拓扑让它保持下来（I1、I2）

- 同样的合成视觉输入，经未学习的解剖 ER 权重只能得到 0.197 的记忆（搜索中的最好得分为 0.325，与 F1g-v2 的约 0.33 一致）；经共激活压低学习后升到 0.465（10 个 seed 中有 9 个提高）。这支持 F1g-v2 的推断：**解剖 ER→EPG 连接本身不携带视觉映射，映射来自可塑性。**
- 学习得到的视觉提示在真实接线中能保持（0.465），在两种零模型中几乎不能（0.201、0.180）。这把 F1c-v4 的结论（真实 CX 拓扑支持持续的提示特异状态）推广到了“经学习视觉通路进入”的提示上，而不再依赖人为的直接 EPG 输入。
- 不过，锚定误差很大（1.14 弧度，约 65°）：真实网络保持的是**可区分**的状态，但它在 EPG 谱环坐标上的位置与训练朝向并不对齐。直接 EPG 提示的锚定误差也有 0.72 弧度。较可能的原因是谱环角度只是 EB 真实楔区位置的粗略近似（F1g 中 PEN 偏移被压缩到 3–6° 也指向这一点），再加上 1 秒延迟内的漂移。

### 3.2 LNO 驱动的转动仍未复现（I3、I4；I5 不能解读为转动）

- I3 与 I4 都不通过。直接 EPG 提示下 A 为 −0.095，左右驱动的作用多数同向。
- I5 按字面通过，但不应解读为“真实接线更会转动”。反对称指数 A 对位移幅度做了归一化，在真实图的两个有效 arm 中，联合最优参数下的转动量中位数只有 0.02–0.04 弧度（1–2°），阳性对照则是 0.42–0.81 弧度。`learned` arm 中有明显位移的 4 个 seed（0.5–1.9 弧度），同一参数下的记忆只有 0.11–0.14，也就是没有 bump；`direct` arm 中位移最大的两个 seed（0.30、0.49 弧度），联合参数下的记忆为 0.35 与 0.26。I5 的差异主要来自零模型在近零位移上 A 的符号为负，而不是真实图出现了有意义的转动。
- 按预注册的描述量交叉检查：没有一个 seed 同时满足“联合记忆 ≥ 0.5、A ≥ 0.5、转动量 ≥ 0.1 弧度”。

## 4. 结论

1. **ER→EPG 可塑性是视觉朝向锚定的必要成分**（I1），而学习得到的视觉提示依赖真实 CX 拓扑才能在黑暗中保持（I2）。在本抽象中，“学习得到的输入映射 + 精确的环拓扑”构成了一个完整的视觉朝向记忆回路。
2. **路径积分在 F1f、F1f-v2、F1g-v2、F1i 四轮中都没有复现。** 现在可以排除的原因有：提示通路（已用学习映射与直接提示两种方式解决）、权重形式（二值）、速度通路（真实 LNO）。剩下最可疑的是**角坐标**：谱嵌入把 PEN 的 ±1 个 PB 小球偏移压缩成了 3–6°，模型中的 PEN→EPG 投射因此几乎没有净偏移可用。下一步应改用 PB 小球或 EB 楔区的解剖标注（例如 hemibrain 的 instance 名称）来定义角度与偏移；FlyWire 的注释表里没有这些标签。
3. 方法学：反对称指数 A 必须与位移幅度一起报告，单看 A 会把噪声级位移当成转动。今后的转动类协议应把“位移幅度 ≥ 阈值”写进主指标。
