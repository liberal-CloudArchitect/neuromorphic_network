# F1l：用 PB 小球相位代替谱嵌入角度，检验 PEN 偏移与 LNO 驱动的转动

## 1. 动机

- 路径积分在 F1f、F1f-v2、F1g-v2、F1i 四轮中都没有复现。提示通路、权重形式、速度通路都已排除，最可疑的是**角坐标**：FlyWire 上的谱嵌入把 PEN 应有的 ±1 个 PB 小球偏移压缩成了 3–6°，锚定误差也很大（F1i：直接提示 0.72 弧度）。
- FlyWire 注释表里没有 PB 小球标签，hemibrain v1.2 的 traced 导出（已在 T1 中下载，`exported-traced-adjacencies-v1.2.tar.gz`）有：例如 `EPG(PB08)_L3`、`PEN_a(PB06a)_R4`。CX 核心类型的数量为 46 个 EPG（L1–L8、R1–R8）、4 个 EPGt、20 个 PEN_a、22 个 PEN_b、18 个 PEG、42 个 Delta7；LNO 家族共 12 个。hemibrain 是 Hulse et al. 2021 CX 连接组所用的数据。
- 因此本轮换成 hemibrain，这也是对 F1c-v4（FlyWire）记忆结论的**跨数据集重复**。

## 2. PB 相位（只用标签，不用连接）

- PB 小球排成一行：L9 … L1 R1 … R9，位置 0–17。Delta7 的输出小球彼此相隔 8 个位置（例如 `Delta7(PB15)_L4R5`、`L1L9R8`），即相隔 8 个位置的小球同相。
- 相位编号 = 位置 mod 8，角度 = −π + (编号 + 0.5)·π/4。每个相位上的 EPG 来自 L_i 与 R_(9−i) 两个小球，约 6 个。
- 递质用 hemibrain 逐 body 的预测（`predicted_nt`）；GABA 与谷氨酸为抑制。

## 3. 结构检查（确定性；冻结后与动力学一起运行）

| ID | 内容 | 通过条件 |
|---|---|---|
| S1 | EPG 两两之间 EB 内连接谱（输入与输出，按 ROI = EB）的余弦相似度，按相位差（0–4 档）分组 | 相位差 0 的平均相似度最高、相位差 4（180°）最低；并且在“L_i 与 R_j 配对，i + j = 9 + k”的规则中，k = 0 的平均相似度最高（k ∈ −4…3） |
| S2 | PEN 偏移：每个 PEN 的 EPG 目标（按突触数加权）的平均相位，减去它自己的 PB 相位；按（类型，侧别）取环形平均 | PEN_a 与 PEN_b 各自左右两侧的偏移符号相反，且每组偏移的绝对值在 22.5°–67.5° 之间 |
| S3 | hemibrain 核心的谱嵌入角度与 PB 相位的对齐程度（允许反射），以及谱坐标下的 PEN 偏移 | 描述性 |
| S4 | Delta7→EPG 突触数随相位差的分布 | 描述性 |

## 4. 动力学模型（与 F1i 的 `direct` arm 相同，只换数据与坐标）

- hemibrain 核心（EPG、EPGt、PEN_a、PEN_b、PEG、Delta7），二值权重（≥ 5 个突触），`relu_tanh`，12 个类型参数，分布同 F1c-v4。
- 提示：每个相位上的 EPG 得到直接输入（8 个提示）；解码用 EPG 的 PB 相位做群体向量。
- 角速度：hemibrain LNO 家族（GLNO、LNO1、LNO2、LNOa），侧别取自 instance 后缀，单侧活动为 a。
- 时序与 F1i 相同。
- **门控转动得分**（F1i 的教训）：R = A × min(1, 平均 |位移| / 0.2 弧度)；联合得分 J = min(记忆, R)。搜索与评估都用 J。
- 搜索：每个 seed 1,000 组候选（rng = 9000 + seed），14 维：12 个类型参数、log₁₀ g_cue ~ U(−1, 1)、log₁₀ a ~ U(log₁₀ 0.05, log₁₀ 5)。同一 seed 内所有图共用同一候选集。评分噪声为 950/951，评估噪声为 200 + seed 与 201 + seed。记忆最优与联合最优分别评估。
- 图：
  - `real`；
  - `type_preserving`、`degree_preserving`（rng = 10000 + seed）；
  - `offset_ablated`：把每条 PEN→EPG 边的目标移回“该（类型，侧别）组在 S2 中测得的平均偏移”，落到角度最接近的 EPG 上（在同角度的 EPG 中保持组内名次），重复的边合并。这是对“PEN 偏移导致转动”的因果性检验。

## 5. 阳性对照与资格检查（seed 990）

理想转动环（全部突触数 × 5）加理想 LNO，用同样的直接提示与门控得分：联合最优参数下记忆 ≥ 0.5 且 J ≥ 0.5 才算通过。同时报告去掉偏移后的理想环（预期 J 很低），作为 `offset_ablated` 逻辑的检验。设计检查（已披露）：冻结前只在 seed 991 上运行过这两个对照，没有在 hemibrain 数据上运行任何结构或动力学分析。结果：完整理想环记忆 1.000、J +1.000（平均位移 0.48 弧度）；去掉偏移后记忆 1.000、J −0.98（A −0.98，左右驱动同向），说明偏移消融能取消反对称转动。

## 7. 解释边界

- hemibrain 只覆盖一个半脑的大部分，但 CX 完整；`traced` 导出只含未截断的神经元。
- PB 相位只用于定义坐标（提示、解码、偏移消融），递归权重完全来自连接组。
- 速度仍被抽象为单侧 LNO 的恒定活动，不涉及积分的定量精度。
