# F1h 结果：预注册比较“支持”，但事后对照显示这是标定区间造成的假象

本报告属于探索层，不构成 Gate 证据。协议在实现和运行之前已冻结并提交（`d1d87c4`）。第 3 节为事后分析，未经预注册。

## 1. 结构与标定

- 48 个 MBON（21 个回避、21 个趋近、6 个未被教导）；2,423 个 KC 与 MBON 之间有 22,304 对连接；153 个 PAM。
- 标定（seeds 900–904，三种日程的平均准确率）选中的参数：

| 变体 | η | 恢复率 ρ | 第三参数 | 标定得分 |
|---|---:|---:|---|---:|
| `none` | 0.03 | 0.003 | g = 1 | 0.756 |
| `ideal` | 0.03 | 0.003 | g = 1 | 0.801 |
| `loop_real` | **1.0** | **0.03** | g_fb = 3 | 0.754 |
| `loop_rewired` | 0.03 | 0.003 | g_fb = 1 | 0.752 |

## 4. 结论

1. **W1 与 W2 的“优势”来自标定区间不同，而不是回路结构。** 参数一致时，`loop_real` 在 volatile 日程中并不优于 `loop_rewired`（快参数下 0.789 vs 0.800，慢参数下 0.634 vs 0.660）。标定之所以只给 `loop_real` 选了“快学快忘”的区间，是因为在慢区间里，真实反馈让 stable 和 noisy 都变差了（0.845 vs 0.903；0.761 vs 0.846），使平均分倒向快区间。
2. **在本抽象中，真实 MBON→DAN 反馈的符号不实现预测误差，反而略微破坏学习。** 这与结构观察一致：回避 MBON 抑制自己的 PAM（560 对 53 个突触）。奖励学习压低回避 MBON 后，PAM 被去抑制，形成正反馈，而不是 RPE 所需的负反馈。
3. F1e 的结构富集（互惠反馈 7.3×）仍然成立，但它的功能不是本模型中的减法式 r − v。可能的功能有：维持或巩固（正反馈）、跨 compartment 的协调，或者在真实系统中依赖受体类型（如谷氨酸的兴奋性 NMDA 受体）而改变符号。这些都超出了本协议的范围。
4. **方法学教训：** 在共同网格、日程平均目标下分别调参的比较，可能让不同变体落在不同的工作区间。今后的协议应同时预注册“参数匹配”的比较。
