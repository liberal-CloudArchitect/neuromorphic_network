# F1a-v3：多峰类别下，稀疏扩展码能否超越原型学习

## 1. 动机

F1a 与 F1a-v2 的类别都是单一原型加噪声。这种情况下，按类均值做最近邻分类（NCM）几乎最优，稀疏码没有可占的位置。

按扩展编码理论（Litwin-Kumar et al. 2017；Cover 定理），扩展加稀疏的价值在于让非线性可分的类别变得线性可分。本实验让每个类别由几种互不相关的气味组成：PN 空间中的类均值会把几个峰混在一起，而稀疏 KC 码在关联读出中可以把各个峰分开存储。

## 2. 任务

- 20 个类别，每个类别由 m = 4 个独立抽取的气味原型组成（共 80 个原型）。原型生成同 F1a：55 个嗅小球，激活概率 0.3，激活值服从 LogNormal(0, 0.5)。
- 每个原型抽 25 个训练样本、25 个测试样本，噪声模型同 F1a；因此每类有 100 个训练样本、100 个测试样本。
- 类增量设置：10 个任务，每个任务 2 类；单输出头，预测在已见过的全部类别中进行。
- 噪声 σ 的标定：只用 seed 999，只用“已知峰标签的 oracle NCM”。它对 80 个原型各做一次 NCM，再映射回所属类别，并做联合训练。在网格 {0.1, …, 3.0} 中选使测试准确率最接近 0.90 的 σ，然后冻结。被比较的模型不参与标定。
- 重复：seeds 20–29，与 F1a、F1a-v2 都不重叠。

## 3. 模型

沿用 F1a 的回路（右半球 PN→KC，权重为突触数）、学习器、训练设置与统计方法。

另加两个描述性参照：

- `pn_knn`：PN 空间的 1-近邻分类（余弦），保存全部训练样本，作为非参数参照。其存储量随样本数增长，`mb_assoc` 的读出参数量则固定为 20 × 2,423。
- `oracle_mode_ncm`：已知峰标签的 NCM，表示信息上限，仅用于参照。

## 4. 预注册比较（Holm family）

| ID | 比较 | 通过条件 |
|---|---|---|
| E1 | `mb_assoc(real,5%)` − `pn_ncm` | Δ ≥ 5pp，CI 下界 > 0，Holm p ≤ 0.05 |
| E2 | `mb_assoc(real,5%)` − `mb_assoc(real,50%)` | Δ ≥ 2pp，CI 下界 > 0，Holm p ≤ 0.05 |
| E3 | `mb_assoc(real,5%)` − `mb_sgd(real,5%)` | Δ ≥ 5pp，CI 下界 > 0，Holm p ≤ 0.05 |
| E4 | `mb_assoc(real,5%)` − `pn_sgd` | Δ ≥ 10pp，CI 下界 > 0，Holm p ≤ 0.05 |
| E5 | `mb_assoc(real,5%)` − `mb_assoc(degree_preserving,5%)` | 95% CI 落在 ±1pp 之内判“等价”，否则“未确定” |

描述性报告：`pn_knn`、`oracle_mode_ncm`、`mlp_sgd`、`mb_perceptron`，稀疏度 1% 与 20%，`real_binary`、`er`、`kc_norm`，以及各条件的遗忘。

## 5. 解释边界

- 若 E1 通过，只说明“扩展加稀疏码在多峰类别下优于类均值原型”，这是一个算法层面的结论。
- 若 E1 通过而 E2 不通过，说明起作用的是扩展本身，而不是稀疏。
- `pn_knn` 用更大的存储换取性能；与它的差距只作描述，不作为裁决依据。
