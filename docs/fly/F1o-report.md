# F1o 结果：统一递质符号后，hemibrain 上的记忆优势完全恢复，并且比 FlyWire 更强

本报告属于探索层，不构成 Gate 证据。协议在正式运行之前已冻结并提交（`0a90baf`）。

## 1. 资格检查（seed 990）

理想环（突触数 × 5）按带下限的规则评估：记忆 1.000，通过。

## 3. 解释

1. 按预先写定的规则（O3 通过，O1、O2 都通过）：**hemibrain 上记忆优势的缺失来自递质标签。** hemibrain 逐 body 的递质预测把大多数 EPG、一半的 PEN 和多数 PEG 标成了谷氨酸，环上大片兴奋性回路因此变成抑制性，bump 被钉在一个位置上（落点有效位置数 1.1，提示对齐 0.03）。按细胞类型统一符号后，bump 能落在多个位置（4.5），并跟随提示（对齐 0.74）。
2. 统一符号后，hemibrain 上真实拓扑的记忆优势（+0.63）**比 FlyWire 更强**（同一批 seed 上 FlyWire 为 0.618 对 0.349，+0.27），real 的记忆接近满分。相对 degree_preserving 也高 +0.42。
3. 因此，“真实 CX 拓扑支持持续的提示特异状态”**在两个独立的连接组上都成立**，前提是递质符号按细胞类型保持一致。F1 总结中这条原理恢复为跨数据集成立。
4. 活动下限再次没有改变结论（无下限规则下的数值几乎相同）。

## 4. 对先前结果的影响

- F1l 的 hemibrain 动力学（P1 记忆、P2/P4 路径积分）、F1m 的 M3/M4、F1n 的全部 hemibrain arm，都建立在错误的符号上，不能再作为“hemibrain 不支持”的证据。各报告已加勘误。
- 特别是 F1l 中 PEN 有一半被当作抑制性，**hemibrain 上的路径积分需要用统一符号重新检验**；在 PB 坐标下 PEN 偏移的结构基础非常清楚（±52–70°，一致性 0.998），这是目前最值得重做的一项。

## 5. 方法学教训

- 用递质预测定符号前，先按细胞类型检查一致性；同一类型内部出现相反符号时，以实验注释或类型多数为准，并在协议中写明来源。
- 跨数据集比较时，“结果不一致”首先要排查注释层面（递质、类型、侧别），本轮在 F1l、F1m、F1n 三轮中都把一个注释问题误当成了接线或组成的差异，直到看了 bump 的落点分布才找到原因。
