# F1f：左右 PEN 的非对称驱动能否让 bump 沿相反方向转动

## 1. 动机

F1c-v4 显示：在类型参数搜索下，真实 CX 接线能维持提示特异的持续状态，而零模型不能。

在果蝇中，左右两侧的 PEN 接收角速度信号，通过 PEN→EPG 的偏移投射推动 bump 转动。本实验检验这种转动是否会作为**涌现性质**出现：所用参数是 F1c-v4 只为“记忆”选出的，从未针对转动做过选择。

## 2. 模型与参数

- 网络与参数：直接沿用 F1c-v4 每个 seed（90–99）中 real、`type_preserving`、`degree_preserving` 各自选中的类型增益与偏置；零模型用相同的 rng(10000 + seed) 重建。
- 动力学：同 F1c（`relu_tanh`；τ = 20 ms；dt = 1 ms；噪声 0.05；运行在 MPS 上）。
- 每个试次：200 ms 基线 → 300 ms 提示（8 个角度区间，同 F1c）→ 500 ms 维持 → 300 ms 速度驱动。速度驱动期间，给某一侧（`side` 注释）的全部 PEN_a 与 PEN_b 加上常量输入 a。
- 读出：速度驱动期最后 100 ms 的 EPG 平均活动；bump 角度用 EPG 的谱嵌入角度做群体向量解码：θ = atan2(Σ r·sin φ, Σ r·cos φ)。
- 三种条件：无驱动、左侧驱动、右侧驱动。每个提示每种条件 10 个试次，噪声相互独立。

## 3. 指标

- 对每个提示 k，先求各条件 θ 的环形均值，再计算转动量 ΔL_k = wrap(θ_left − θ_none) 与 ΔR_k = wrap(θ_right − θ_none)。
- 反对称指数 A = −Σ_k ΔL_k·ΔR_k ÷ (½ Σ_k (ΔL_k² + ΔR_k²))，取值在 [−1, 1]：
  - 左右驱动产生等量、相反的转动时，A = +1；
  - 两者无关（例如没有 bump、角度随机）时，A ≈ 0；
  - 同方向转动时，A = −1。
- 速度幅度 a ∈ {0.1, 0.3, 1.0}：对每张图分别在标定噪声 seed 951 上选使 A 最大的值；所有图规则相同。正式评估的噪声 seed 为 100 + seed。

## 4. 预注册比较（seeds 90–99；Holm family）

| ID | 比较 | 通过条件 |
|---|---|---|
| R1 | real 的 A − 0 | 均值 > 0，CI 下界 > 0，Holm p ≤ 0.05 |
| R2 | real − `type_preserving` | Δ ≥ 0.2，CI 下界 > 0，Holm p ≤ 0.05 |
| R3 | real − `degree_preserving` | Δ ≥ 0.2，CI 下界 > 0，Holm p ≤ 0.05 |

描述性报告：选中的幅度，以及 \|ΔL\|、\|ΔR\| 的平均转动量（弧度）。

## 5. 解释边界

- 角速度输入被抽象为一侧 PEN 的常量驱动，不包含 LNO 等上游回路的结构。
- 方向的正负由谱嵌入的角度约定决定，不对应真实的顺时针或逆时针；A 只衡量左右是否相反。
