# F1q 结果：PEN→EPG 映射是路径积分的因果成分；打乱它只取消转动、不取消记忆，镜像它会让方向反转

本报告属于探索层，不构成 Gate 证据。协议在正式运行之前已冻结并提交（`892b963`）；冻结前只在 seed 991 上运行过理想环对照。第 3 节的残余偏移分析为事后分析。

## 1. 资格检查（seed 990）

理想转动环在两种驱动下三道门全部通过：完整环 J ≥ 0.5；去掉偏移后 J 大幅下降；镜像后 J ≥ 0.5 且方向相反。R1–R7 全部有效。

## 3. 为什么“去掉偏移”没有取消转动（事后）

`offset_zeroed` 是在 PB 标签相位上把偏移设为 0。但 F1l 的事后分析表明，左右两半 PB 在 EB 中交错约半个相位（左半边整体平移 +22.5°–28° 时，EB 连接相似度与角距离的拟合最好）。在这个校正后的坐标里：

| 图 | PEN_a 左 | PEN_a 右 | PEN_b 左 | PEN_b 右 |
|---|---:|---:|---:|---:|
| real | +57.8° | −55.4° | +55.2° | −54.3° |
| `offset_zeroed` | **−10.3°** | **+10.1°** | **−9.7°** | **+10.9°** |
| `offset_mirrored` | −79.3° | +77.0° | −75.4° | +75.4° |

（左半边平移 +22.5° 时的值；平移 +28.1° 时 `offset_zeroed` 为 −12.8/+12.6/−12.2/+13.6°。）

“去掉偏移”实际上留下了约 ±10–13° 的**反向**偏移，相当于一个较弱的镜像。理想环的偏移只有 7.5°，同样足以驱动转动，所以 `offset_zeroed` 仍然转动，而且方向与 real 相反（`lno` 2/10、`pen` 0/10 为正）。R2、R5 未通过，是因为操作本身没有达到“零偏移”，而不是因为偏移无关紧要；它的方向结果与 R4、R7 一致。

## 4. 结论

1. **PEN→EPG 映射是本模型中路径积分的因果成分。**
   - 只打乱这一块的目标（其余连接不变），转动消失（R3、R6），但记忆基本保留（0.910 对 0.978）：**保持朝向与更新朝向在接线上可以分离**，前者依赖 EPG/Delta7 等回路，后者依赖 PEN→EPG 的拓扑。
   - 偏移的符号决定转动方向：镜像后方向反转（R4、R7）；残留反向偏移的 `offset_zeroed` 也反转。
   - 在 LNO 驱动下，真实接线的转动方向与“对侧 LNO + PEN 偏移”的结构预测一致（R1，9/10）。
2. 加上 F1o、F1p，CX 这条线形成了一条完整的结论链：真实拓扑支持朝向记忆（两个连接组）；真实拓扑支持路径积分（hemibrain）；路径积分的方向与存在都由 PEN→EPG 的偏移拓扑决定。
3. 直接 PEN 驱动下的绝对方向不稳定（7/10），符合设计检查中发现的饱和效应：强驱动会抹平被驱动一侧的调制。

## 5. 方法学教训

- “去掉偏移”必须在正确的坐标里做：PB 标签相位与 EB 位置之间存在半格交错，标签坐标中的“零偏移”在 EB 坐标中是 ±10–13° 的反向偏移。
- 方向指标在这一轮发挥了决定性作用：只看反对称（J）时，镜像、去偏移与真实接线几乎没有差别；看方向后，因果关系一目了然。
