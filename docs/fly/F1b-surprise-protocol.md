# F1b：预测误差门控的可塑性，能否让 MB 读出适应无提示的价值反转

## 1. 动机与结构依据

P3–P5 中，预测模块连续失败，原因之一是任务里没有“需要发现变化”的位置。本实验构造一个只有靠预测误差才能及时适应的任务：气味的奖惩价值会在没有任何提示的情况下反转。

结构依据（FlyWire 783，右半球）：165 个 DAN 中有 164 个接收 MBON 输入，35 种 MBON 类型全部投射到 DAN。MBON 输入占 DAN 输入突触的 4.0%，KC 输入占 53.6%。这为“DAN 信号 = 奖惩 − MBON 预测”的抽象提供了解剖通路，但不证明果蝇按这种方式计算。

## 2. 任务

- 气味：20 个单峰原型，生成方式同 F1a，σ = 0.4（F1a-v4 已确认此区间的 KC 码可靠）。每个试次抽取一个新的噪声样本。
- 编码：右半球真实 PN→KC 二值接线，5% k-WTA（F1a-v4 的主条件）。
- 价值：每个气味的初始价值独立取 ±1。
- 每个试次：均匀随机选一个气味 → 学习器给出预测 v → 若 v > 0 则“接近”，否则“回避” → 收到奖惩 r → 学习。
- 3 种日程，每种 2,000 个试次：
  - `stable`：价值不变，r = 价值；
  - `volatile`：每 200 个试次，随机选一半气味把价值反号，不给任何提示；r = 当前价值；
  - `noisy`：价值不变，但 r 以 0.8 的概率等于价值、0.2 的概率取反。
- 判对标准：决策与当前真实价值的符号一致；`noisy` 日程按底层价值判对。

## 3. 学习器（读出均作用于 KC 码 z，k 为活跃 KC 数）

| ID | 规则 |
|---|---|
| `kc_hebb` | 纯关联：r = +1 时 w₊ += η·z/k，r = −1 时 w₋ += η·z/k；v = (w₊ − w₋)·z。没有误差项，等同 F1a 规则 |
| `kc_delta` | 预测误差门控（Rescorla–Wagner，DAN = r − v）：w += η·(r − v)·z/k，学习率 η 固定 |
| `kc_surprise` | 全局 surprise 调制学习率（Pearce–Hall 式，类似 DAN 张力）：α ← (1 − γ)·α + γ·\|r − v\|，初始 α = 1；w += η·α·(r − v)·z/k |
| `pn_delta` | 与 `kc_delta` 规则相同，但直接作用于 L2 归一化后的 PN 输入，不经 KC 扩展 |

## 4. 超参数（对每个学习器同样公平地标定）

- 网格：η ∈ {0.03, 0.1, 0.3, 1.0}；`kc_surprise` 另加 γ ∈ {0.05, 0.2}。
- 标定只在 seeds 900–904 上进行，目标是三种日程的平均准确率，因此任何学习器都不会只针对某一种日程调参。
- 选定的超参数冻结后，在 seeds 40–49 上评估。

## 5. 指标与预注册比较（Holm family；统计方法同 F1a）

- 主指标：各日程全部试次的平均准确率。
- 次指标：`volatile` 日程中每次反转后前 50 个试次、被反转气味上的准确率。

| ID | 日程 | 比较 | 通过条件 |
|---|---|---|---|
| H1 | volatile | `kc_delta` − `kc_hebb` | Δ ≥ 10pp，CI 下界 > 0，Holm p ≤ 0.05 |
| H2 | volatile | `kc_surprise` − `kc_delta` | Δ ≥ 3pp，CI 下界 > 0，Holm p ≤ 0.05 |
| H3 | noisy | `kc_surprise` − `kc_delta` | 非劣：95% CI 下界 > −2pp |
| H4 | volatile | `kc_delta` − `pn_delta` | Δ ≥ 3pp，CI 下界 > 0，Holm p ≤ 0.05 |

H3 只看 CI；它的 p 值单独报告，不纳入 Holm 裁决。

## 6. 解释边界

- 若 H1 通过，只说明“预测误差门控是适应无提示反转的必要成分”，这是一个算法层面的结论。
- H2 检验全局 surprise 调制学习率（类似注意或张力性多巴胺）是否在波动环境中带来额外收益；H3 检验它在纯噪声环境中会不会过度反应。
- 结论不推广到果蝇 DAN 的真实编码方式；MBON→DAN 通路只提供结构可行性。
