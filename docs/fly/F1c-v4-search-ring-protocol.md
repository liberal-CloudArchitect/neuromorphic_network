# F1c-v4：等预算随机搜索类型参数，比较真实接线与零模型

## 1. 动机与诊断

F1c-v3 在资格检查阶段失败：连理想环的阳性对照也停在机会水平，损失为 ln 8。

为分清原因，我只用阳性对照（不涉及任何协议 seed）做了一次参数网格诊断：理想环在 F1c 的模型类中有大量参数点能达到 100% 记忆准确率，`relu_tanh` 与 `tanh_softplus` 两种激活函数都可以。因此，失败的原因是 **BPTT 优化**：从增益 1 出发，梯度无法穿过 1,000 ms 的延迟期把网络带进吸引子区域；而不是模型类本身表达不了环形吸引子。

## 2. 方法

- 模型类与 F1c 完全相同：`relu_tanh` 激活，突触数权重按中位输入归一化，相同的试次时序、噪声与提示区间。运行设备为 MPS（所有图都用同一设备）。
- 参数：每种突触后细胞类型一个增益和一个偏置，共 6 种类型 × 2 = 12 个参数。
- 候选集：每个 seed 抽 1,000 组候选参数。log₂ 增益服从 U(−2, 5)，即增益在 0.25 到 32 之间；偏置服从 U(−1.5, 0.5)；候选 RNG 的 seed 为 3000 + seed。**同一个 seed 内，所有图使用完全相同的候选集。**
- 选择：每组候选在标定噪声 seed 950 上，用每个提示 5 个模板试次、5 个测试试次评分（模板解码）；取得分最高者，并列时取第一个。
- 评估：用选中的参数、F1c 的评估规模（每个提示 10 个模板、10 个测试试次），评估噪声 seed 等于 seed 本身。

## 3. 资格检查（seed 990，正式 seed 之前运行）

- 阳性对照 `ideal_ring_circuit()`：只用候选向量中 EPG 与 Delta7 两个类型的参数；搜索与评估流程同上。
- 通过条件：阳性对照的评估准确率 ≥ 0.5。不满足则本协议判定为 INVALID，不使用 seeds 90–99。

## 4. 正式比较（seeds 90–99；零模型生成方式同 F1c；Holm family）

| ID | 比较 | 通过条件 |
|---|---|---|
| P1 | real 准确率 − 0.5 | 均值 > 0，CI 下界 > 0，Holm p ≤ 0.05 |
| P2 | real − `type_preserving` | Δ ≥ 20pp，CI 下界 > 0，Holm p ≤ 0.05 |
| P3 | real − `degree_preserving` | Δ ≥ 20pp，CI 下界 > 0，Holm p ≤ 0.05 |

描述性报告：各图搜索阶段的最好得分、选中的参数、延迟期活动水平。

## 5. 解释边界

- 搜索预算有限（每个 seed 1,000 组），零模型也可能存在搜索没找到的吸引子区域。因此 P2 与 P3 回答的是：在相同搜索预算下，哪种拓扑更容易找到记忆区域。
- 均匀随机搜索在 12 维空间里的覆盖很稀疏；结论只针对本预算。
