# F1k 结果：KC 侧突触标签把回路从“共模漂移”变成记忆特异的巩固；兴奋性谷氨酸只消除漂移

本报告属于探索层，不构成 Gate 证据。协议在正式运行之前已冻结并提交（`5b25232`）；冻结前只用非正式的 seed 996 做过冒烟测试（已在协议中披露），K6、K7 由该测试启发。

## 1. 资格检查（seeds 990–994）

- 任务门：`replay_oracle` − `none` = +0.073（门槛 0.02），通过。
- 机制门：`loop_positive_tag` − `none` = +0.032（门槛 0.02），通过。说明标签机制在本模型中能够产生巩固；K1、K3 有效。

网格稳健性：`loop_real_tag` 的趋近指数在 24 个网格点上**全部**高于 `none`。标签保留率越高效应越大（λ = 0.999 时 0.087，λ = 0.99 时 0.068，`none` 为 0.055）；学习率越高效应也越大（η = 1 时 0.094 对 0.061）。

## 3. 描述性结果

- **巩固不需要再暴露：** `retention_novel`（第二阶段全是新异气味）中，`loop_real_tag` 的趋近指数为 0.076，与有再暴露时的 0.077 几乎相同。驱动来自任何气味引起的共模反馈，特异性来自标签，属于“标签与捕获”式的巩固。
- **巩固量：** 标签回路得到的巩固约为重放预言机的 40%（(0.077 − 0.055)/(0.111 − 0.055)）。
- **残留的泛化：** 标签把新异气味的假趋近率从 0.261 降到 0.043，但没有降到 `none` 的 0.001；重连回路加标签后仍有 0.115。
- **兴奋性谷氨酸：** 漂移消失（K4、K5），但获得阶段的记忆变弱（0.095 对 0.113），保持后的趋近指数也更低（0.032）。原因在于反馈变成了负反馈，强化期间对已学会的气味减小教学信号（类似只有正半部分的 RPE，没有经 DAN 活动下降实现的消退）。加上标签后（`loop_glu_tag`），残留的 GABA 正反馈环与标签结合，也能巩固（0.069）。
- **反转代价：** F1j（+0.019）与 F1k（+0.018）中，回路变体在反转任务上都比 `none` 少反转约 0.02，CI 都完全大于 0，但都低于各自预注册的 0.02 门槛。

## 4. 结论

1. **KC 侧突触标签能把 MBON→DAN 回路变成记忆特异的巩固机制**（K1、K2；24/24 个网格点）。反馈驱动本身仍然是非特异的；特异性来自“哪些突触在强化时被打过标签”。
2. **这种作用不依赖真实接线**（K3、K6 不支持）：保度重连的反馈加上标签同样巩固。F1e 的互惠富集（7.3×）在 F1h、F1j、F1k 的三种功能检验中都没有找到功能上的必要性。
3. **兴奋性谷氨酸只消除漂移，不带来巩固**（K4、K5）：它把回避侧的正反馈变为负反馈，代价是获得变弱。
4. 结合 F1j：同一个非特异的正反馈回路，没有标签时改变整体效价状态，有标签时巩固单条记忆。**决定功能的是突触级的门控，而不是回路的接线细节。**

## 5. 对类脑设计的启示

- 巩固与记忆维持可以用“广播式调制信号 + 突触级资格标签”实现：调制信号不需要知道是哪条记忆，标签决定哪些突触被捕获。这比为每条记忆设计专门的重放通路便宜得多，效果约为理想重放的 40%。
- 标签的寿命是关键参数（λ = 0.999 优于 0.99）；没有标签的全局正反馈会造成整体偏向，必须避免。
