# F1a-v4：确认事后发现的“低噪声下稀疏码优于原型学习”

## 1. 来源（事后发现，需要确认）

F1a-v3 的预注册比较 E1 不通过（σ = 0.9，噪声由 oracle 标定）。

事后的探索性敏感性分析（seeds 20–24，与 v3 的预注册 seeds 部分重叠，因此只能算探索）显示：σ ≤ 0.4 时，二值真实接线的 5% 码明显优于 `pn_ncm`；σ = 0.4 时为 0.904 vs 0.762，σ = 0.2 时为 0.984 vs 0.849。同一气味样本之间 KC 码的 Jaccard 重叠随噪声升高而下降（σ = 0.2 时 0.59，σ = 0.9 时 0.21），稀疏码的优势也随之消失。

为什么选 `real_binary` 为主条件：在 F1a、F1a-v2 与 F1a-v3 三个实验中，它都是 5% 码里最好的 MB 变体（描述性结果一致），不是从单次结果中挑出来的。

## 2. 设计

- 任务、回路、读出和统计同 F1a-v3（20 类 × 4 峰，每峰训练 25 个、测试 25 个样本，每个任务 2 类）。
- 噪声：σ ∈ {0.2, 0.4}，直接固定，不做标定。
- 新 seeds：30–39，与以往全部实验不重叠。
- 二值零模型：对每个 seed 的 `degree_preserving` 与 `er` 重连图同样取二值权重。

## 3. 预注册比较（Holm family）

| ID | σ | 比较 | 通过条件 |
|---|---|---|---|
| G1 | 0.4 | `mb_assoc(real_binary,5%)` − `pn_ncm` | Δ ≥ 5pp，CI 下界 > 0，Holm p ≤ 0.05 |
| G2 | 0.2 | `mb_assoc(real_binary,5%)` − `pn_ncm` | Δ ≥ 5pp，CI 下界 > 0，Holm p ≤ 0.05 |
| G3 | 0.4 | `mb_assoc(real_binary,5%)` − `mb_assoc(real_binary,50%)` | Δ ≥ 2pp，CI 下界 > 0，Holm p ≤ 0.05 |
| G4 | 0.4 | `mb_assoc(real_binary,5%)` − `mb_assoc(degree_preserving_binary,5%)` | 95% CI 落在 ±1pp 之内判“等价”，否则“未确定” |

描述性报告：突触数权重、`er_binary`、`pn_knn`、`oracle_mode_ncm`、20% 稀疏，以及同峰与异峰的平均 KC 码 Jaccard 重叠。

## 4. 解释边界

- G1 或 G2 通过，只确认“在码可靠的低噪声区，扩展加稀疏码在多峰类别上优于类均值原型”，这是一个算法层面的结论，依赖于输入噪声区间。
- 这里的噪声水平是人为设定的，没有与果蝇 PN 的真实试次间变异做标定。
