## 3. 全脑 LIF 复现（F0-05）

- 设置：v630 连接组；刺激论文中的 21 个糖 GRN；30 个 trial，每个 1 s；dt 0.1 ms；参数取上游 `default_params`。
- 对照：上游 Brian2 的参考输出 `sugarR.parquet`（200 Hz）和 `sugarR_100Hz.parquet`。

| 刺激 | 设备 | MN9 Hz（ours / ref） | 对侧 MN9 Hz | 活跃神经元（ours / ref / 重叠） | 逐神经元 rate Pearson | 平均绝对差 |
|---|---|---|---|---|---:|---:|
| 100 Hz | CPU | 71.1 / 67.0 | 50.4 / 48.6 | 415 / 404 / 399 | 0.9995 | 0.63 Hz |
| 200 Hz | CPU | 94.2 / 93.3 | 63.7 / 61.8 | 453 / 448 / 442 | 0.9998 | 0.55 Hz |
| 200 Hz | MPS | 93.9 / 93.3 | 62.7 / 61.8 | 443 / 448 / 441 | 0.9998 | 0.52 Hz |

单次 1 s × 30 trial 的墙钟：CPU 约 6 分钟，MPS 约 11 分钟。传播已改为事件驱动；目前瓶颈是全神经元状态更新，所以 MPS 并不比 CPU 快。

### 3.1 关键发现：不应期内的突触输入必须丢弃

第一版实现让不应期内到达的突触输入累积到 g，结果下游放电率系统性偏高：一跳神经元高约 19%，MN9 为 119–122 Hz，参考值为 93 Hz。

被刺激的 GRN 本身与参考一致（比值 0.99），所以偏差来自突触传递环节。在 10 trial 上做语义对照的结果如下：

| 变体 | MN9（ref 93.3） | 下游中位比值 | 逐神经元 r |
|---|---:|---:|---:|
| 不应期内累积输入 | 119.1 | 1.22 | 0.967 |
| **不应期内丢弃输入** | **93.9** | **1.00** | **1.000** |
| 不重置 g | 269.4 | 2.13 | 0.023 |

因此 `LIFParameters.refractory_input` 默认取 `"discard"`；`"accumulate"` 仅保留作敏感性对照。这一点是实现语义上的发现：“同一份连接组加同样的参数”不足以确定模拟结果，F1 中所有基于 LIF 的结论都必须声明这一选择。

## 4. 可复现性（F0-06）

- CPU：同 seed 结果逐位一致（单元测试覆盖）。
- CPU 与 MPS：两者的 RNG 流不同，所以按统计容差比较。200 Hz 下 MN9 相差 0.3 Hz，两者对参考的逐神经元 r 都是 0.9998。
- 用概率为 1 的确定性驱动时，CPU 与 MPS 的发放计数逐位一致（单元测试覆盖）。

## 5. 方法学说明与限制

- 复现判据（rate 相关 ≥0.99、MN9 偏差 <10%）是在第一轮诊断之后写下的，不是事先登记的判据，因此本节结论只能视为工程复现，不是预注册检验。
- 100 Hz 下 MN9 仍高约 6%（71.1 vs 67.0 Hz）。参考值的 trial 间 SD 约 3 Hz，这个差距可能来自剩余的调度细节，记为未解释残差。
- 本模型只给出连接组加均匀 LIF 参数下的定性传播结果，不代表果蝇真实的神经生理动态。
