# F1s：直接搜索“积分器”，比较真实接线与三种零模型

## 1. 动机

F1r 表明，F1p 按“记忆 + 300 ms 末尾转动”选出的解中，每种驱动只有 4/10 是真正的积分器（恒速转动、速度随驱动分级），其余是一次性位移；原因是那个选择目标分不清积分与位移。本协议把积分本身作为搜索目标，并与零模型比较。

## 2. 方法

- **模型**：与 F1p 相同（hemibrain 核心按类型统一递质符号、突触数权重、`relu_tanh`、12 个类型参数；LNO 输入按类型统一符号；直接 EPG 提示，8 个 PB 相位；PB 相位解码）。两种速度驱动：`lno` 与 `pen`。
- **积分得分** I = min(记忆, clip(P, 0, 1), clip(G / 1 rad/s, 0, 1))：
  - 记忆：F1p 的延迟期模板准确率，带活动下限（不满足者不参与选择）；
  - P（持续性）与 G（分级性）的定义同 F1r：在 1,000 ms 单侧驱动下，取去漂移后左右驱动的反对称转角 s(t)，方向取 1 倍幅值下 1 秒末的符号；P = 后半秒速度 / 前半秒速度（截断到 [−1, 2]），G = 后半秒速度(a) − 后半秒速度(0.25a)；
  - 驱动期间每个条件都必须满足活动下限（EPG 平均活动 ≥ 0.05 且空间标准差 ≥ 0.05），否则 P、G 记为 0。
- **搜索**：每个 seed 1,000 组候选（rng = 16000 + seed；分布同 F1p：类型增益 2^U(−2, 5)、偏置 U(−1.5, 0.5)、log₁₀ g_cue ~ U(−1, 1)、log₁₀ a ~ U(log₁₀ 0.05, log₁₀ 5)），同一 seed 内所有图共用同一候选集。记忆搜索噪声 950（每个提示 5 个试次）；积分搜索噪声 952，驱动强度 {0.25, 1} 倍，每个提示 2 个试次，每 100 ms 解码一次。
- **评估**（独立噪声）：选中的候选用评估噪声 200 + seed 重测记忆（每个提示 10 个试次），用 201 + seed 重测积分（强度 {0.125, 0.25, 0.5, 1, 2, 4} 倍，每个提示 5 个试次，每 10 ms 解码一次），重新计算 I。
- **图**：real；`type_preserving` 与 `degree_preserving`（rng = 10000 + seed）；`pen_shuffled`（只在 PEN→EPG 边之间交换目标，rng = 15000 + seed；F1q 中它取消了转动、保留了记忆）。

## 3. 阳性对照与资格检查（seed 990）

理想转动环（突触数 × 5，理想 LNO），完整与 `pen_shuffled` 两种，两种驱动分别判定：

- `intact`：完整环评估得分 I ≥ 0.5；
- `shuffled`：完整环有效，且打乱后的 I 至少比完整环低 0.3。

`*_shuffled` 比较（S3、S6）只在对应的 `shuffled` 门通过时有效，其余比较只要求 `intact` 门。

设计检查（已披露）：冻结前只在 seed 991 上运行过对照：完整环在两种驱动下 I = 1.000（P = 1.06 / 1.00，G = +1.43 / +2.87 rad/s）；打乱 PEN→EPG 后 I = 0.000。没有在 hemibrain 数据上运行。

## 4. 预注册比较（seeds 230–239；Holm family 为 S1–S6 中有效的部分）

| ID | 驱动 | 比较 | 通过条件 |
|---|---|---|---|
| S1 | `lno` | real I − 0 | 均值 ≥ 0.5，CI 下界 > 0，Holm p ≤ 0.05 |
| S2 | `lno` | real − `type_preserving` | Δ ≥ 0.3，同上 |
| S3 | `lno` | real − `pen_shuffled` | Δ ≥ 0.3，同上 |
| S4 | `pen` | real I − 0 | 均值 ≥ 0.5，同上 |
| S5 | `pen` | real − `type_preserving` | Δ ≥ 0.3，同上 |
| S6 | `pen` | real − `pen_shuffled` | Δ ≥ 0.3，同上 |

解释规则：S1 通过，说明以积分为目标时，真实接线能稳定地找到积分器；S2、S3 通过，说明这种能力依赖真实拓扑，且具体依赖 PEN→EPG 的拓扑。

描述性报告：`degree_preserving`；评估时的 P、G、s(t) 线性 R²、各强度下的后期速度；搜索中 I ≥ 0.5 的候选比例（积分器在参数空间中有多常见）。

## 5. 解释边界

- 只测“恒定输入 → 恒定角速度、速度随输入分级”，不测变速输入下的积分误差，也不标定到真实角速度。
- 搜索与评估都只在统一类型参数的抽象中进行。
