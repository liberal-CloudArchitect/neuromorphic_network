# F1r：恒定单侧驱动下，bump 是以恒定速度持续转动，还是只移到一个新位置就停下

## 1. 动机

F1p/F1q 表明，hemibrain CX（按类型统一递质符号）在单侧 LNO 或 PEN 驱动下左右相反地转动 bump，方向由 PEN→EPG 偏移决定。但它们只在 300 ms 驱动的最后 100 ms 读一次位置，分不清两种情况：

- **积分**：转角随驱动时间线性增长，角速度由驱动强度决定（路径积分所需的性质）；
- **位移**：bump 移到一个新的平衡位置后停下，转角很快饱和。

## 2. 方法

- **被测对象**：F1p 中 real 图在 seeds 210–219 上的联合最优参数（`f1p_pi_signs_report.json` 中每个 seed、每种驱动的 `candidate`、`amplitude` 与 `cue_gain`）；模型、权重、符号与 F1p 完全相同（`fly_f1p_pi_signs.Rotating`）。参数不重新搜索。
- **时程**：200 ms 基线 → 300 ms 提示（8 个 PB 相位，每个 5 个试次）→ 500 ms 保持 → **1,000 ms** 单侧驱动；驱动强度为选中幅值 a* 的 {0.125, 0.25, 0.5, 1, 2, 4} 倍，另加无驱动条件。每 10 ms 解码一次 EPG 群体向量角（`simulate_trace`），沿时间解缠绕。噪声 seed 为 400 + seed。
- **信号**：每种条件对试次和提示取平均，得到转角曲线；减去无驱动条件（去漂移），再取左右驱动的反对称部分 s(t) = (θ_L − θ_R) / 2。方向取 a* 时 1 秒末的符号（方向已在 F1q 检验，这里只测速度与持续性）。
- **指标**（在 a* 下）：
  - 早期速度 v₁ = s(500 ms) / 0.5 s，后期速度 v₂ = [s(1000 ms) − s(500 ms)] / 0.5 s；
  - **持续性** P = v₂ / v₁（截断到 [−1, 2]；|v₁| ≤ 0.05 rad/s 时记为 0）。恒速转动时 P ≈ 1，一次性位移时 P ≈ 0；
  - **分级性** G = v₂(a*) − v₂(0.25 a*)（rad/s）：角速度是否随驱动强度增大；
  - 描述性：s(t) 线性拟合的 R²、1 秒总转角、各强度下的后期速度（速度—驱动曲线）、Spearman 秩相关。
- **活动下限**：驱动期间每个条件的 EPG 平均活动 ≥ 0.05 且空间标准差 ≥ 0.05（F1m）；任一条件不满足，则该 seed 的 P 与 G 记为 0。

## 3. 阳性对照与资格检查（seed 990）

理想转动环（突触数 × 5，理想 LNO）按 F1p 的方法搜索得到参数，再做同样的时程测量；每种驱动分别判定：P ≥ 0.5 且 G ≥ 0.5 rad/s。

**设计检查（已披露）**：冻结前只在 seed 991 上运行过对照：两种驱动下 P = 1.02，s(t) 线性 R² = 1.00，1 秒转 3.08 弧度；速度—驱动曲线有阈值与饱和（LNO：0.125–0.25 倍时为 0，0.5 倍时 1.34 rad/s，≥ 1 倍时饱和在 3.12 rad/s）。初稿用 Spearman 秩相关（门槛 0.6）检验速度随驱动单调增加，但饱和段的并列使对照只得到 0.60；因此改为分级性 G，并把强度网格向下扩展到 0.125 倍。没有在 hemibrain 数据上运行时程。

## 4. 预注册比较（seeds 210–219；Holm family 为 T1–T4 中有效的部分）

| ID | 驱动 | 指标 | 通过条件 |
|---|---|---|---|
| T1 | `lno` | 持续性 P | 均值 ≥ 0.5，CI 下界 > 0，Holm p ≤ 0.05 |
| T2 | `lno` | 分级性 G | 均值 ≥ 0.5 rad/s，同上 |
| T3 | `pen` | 持续性 P | 均值 ≥ 0.5，同上 |
| T4 | `pen` | 分级性 G | 均值 ≥ 0.5 rad/s，同上 |

解释规则：T1 与 T2（或 T3 与 T4）同时通过，判定真实接线在该驱动下实现了**积分**（恒速转动、速度随输入分级）；T1 不通过而转角仍不为 0，判定为**位移**而非积分。

## 5. 解释边界

- 只测“恒定输入 → 恒定角速度”与速度分级，不测与真实角速度的定量标定，也不测变速输入的积分误差。
- 参数是 F1p 按“记忆 + 300 ms 转动”选出的，不是为积分精度选的；结果反映这些解的性质，而不是模型类能达到的最好积分。
