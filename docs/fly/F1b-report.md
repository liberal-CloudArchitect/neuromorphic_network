# F1b 结果：预测误差门控 vs. 全局 surprise 调制

本报告属于探索层，不构成 Gate 证据。协议在实现和运行之前已冻结并提交（`089fd06`）。

## 1. 标定（seeds 900–904，三种日程平均准确率）

| 学习器 | 选中的超参数 | 标定得分 |
|---|---|---:|
| `kc_hebb` | η = 1.0 | 0.750 |
| `kc_delta` | η = 0.3 | 0.903 |
| `kc_surprise` | η = 0.3，γ = 0.2 | 0.903 |
| `pn_delta` | η = 0.3 | 0.879 |

## 2. 结果（seeds 40–49，平均准确率）

| 学习器 | stable | volatile | noisy | volatile 反转后恢复* |
|---|---:|---:|---:|---:|
| `kc_hebb` | 0.779 | 0.593 | 0.817 | 0.321 |
| `kc_delta` | **0.985** | **0.798** | 0.934 | 0.197 |
| `kc_surprise` | 0.979 | 0.782 | **0.949** | 0.226 |
| `pn_delta` | 0.972 | 0.806 | 0.884 | 0.304 |

\* 每次反转后前 50 个试次内、被反转气味上的准确率。在 50 个试次里，每个气味平均只出现约 2.5 次，所以这个指标主要反映“第一次遇到反转”时的错误，各学习器都偏低。`kc_hebb` 在这一项较高，但整体准确率最低，不能解读为它更会恢复。

## 4. 结论

1. **适应无提示变化，靠的是预测误差门控的可塑性（DAN = r − v）。** 纯关联学习只会累加证据、不会“撤销”，在反转日程中比预测误差规则低 20.5pp，在稳定日程中也低约 21pp（0.779 vs 0.985）。这正是主线 P3–P5 中预测模块一直缺少的“非它不可”的位置：**预测误差最有价值的用途是门控学习（写入强度），而不是改写感觉表示或调制路由。**
2. **全局 surprise 调制学习率（Pearce–Hall 式）在波动环境中没有额外收益。** 原因之一是：反转只涉及一半气味，全局信号却同时放大了所有气味的学习。它在奖励有噪声的环境中反而略有帮助（+1.5pp）。“刺激特异的 associability”等变体属于新假说，需要另立协议。
3. **在单峰、彼此可分的气味上，KC 扩展对价值学习没有帮助（H4）。** 这与 F1a 的结论一致：KC 码的价值出现在多峰或多实例类别上。

## 5. 可迁回主线的原理（需要新协议与 CR）

- 主网络的预测模块应当把预测误差用作**可塑性门控**：在 surprise 高时提高情景或工作记忆的写入率，或驱动价值读出做误差驱动的更新；不要用它来修正当前表示（P4 已失败）或调制路由（P5 中未证明有效）。
- 对应的主线任务应包含**无提示的规则或价值变化**，例如无 cue 版本的 DRS。
