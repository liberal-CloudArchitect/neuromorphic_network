# F1d：真实接线对嗅小球的采样偏好，在真实气味上是否有益

## 1. 动机

F1a 系列中，所有实验都用合成气味。在那种输入下，真实接线比保度重连零模型略差，而且不能确定是否等价。

Zheng et al. 2022 报告，PN→KC 连接偏向过度采样某些（多与食物相关的）嗅小球。需要注意两点：

- 保度零模型（`degree_preserving`）保留每个 PN 的出度，因此**也保留了嗅小球的采样频率**，打乱的只是“哪些嗅小球汇聚到同一个 KC 上”；
- 要检验采样偏好本身，需要一个“嗅小球均匀采样”零模型。

## 2. 数据（DoOR.data commit db323a4，CC BY-SA 4.0，经用户批准下载并按 checksum 校验）

- 用 `door_mappings.csv` 把受体映射到嗅小球。每个嗅小球只取测量最多的一个受体；只保留与 FlyWire 右半球 55 个嗅小球匹配的嗅小球。
- 取测量量最大的 28 个嗅小球，以及在这 28 个嗅小球上至少 90% 有测量的气味（预计约 56 种）。缺失值填 0。气味 × 嗅小球矩阵的取值在 [0, 1]。
- PN 活动：属于这 28 个嗅小球的 PN 取所在嗅小球的响应；其余 PN 取 0。
- 噪声：与 F1a 相同的乘性加加性模型（per-PN 噪声 0.05）。σ 只用 seed 999 和 `pn_ncm` 的联合训练标定，在网格 {0.05, 0.10, …, 1.50} 中选使准确率最接近 0.80 的值，然后冻结。

## 3. 任务与模型

- 每种气味是一个类别；每类抽 20 个训练样本、20 个测试样本；联合训练（一次性训练全部类别，不分任务），用来检验表示的判别力。
- 主编码：二值 PN→KC 连接（F1a 系列中最好的 MB 变体），5% k-WTA；读出用 `AssociativeReadout`（关联读出，相当于 KC 空间中的类原型）。
- 拓扑（seeds 70–79，每个 seed 重新抽取零模型实现）：
  - `real`；
  - `degree_preserving`：同 F1a；保持嗅小球采样频率，打乱汇聚组合；
  - `glomerulus_uniform`：每个 KC 保留原来的输入数，每个输入先在 55 个嗅小球中均匀选一个，再在该嗅小球的 PN 中均匀选一个；同一 KC 内不允许重复的 PN。它去除了采样偏好。

## 4. 预先定义的“偏好气味”（运行前按公式固定，不看结果）

- 嗅小球的采样偏好：b_g = 真实图中来自嗅小球 g 的 KC 输入边数 ÷ 28 个嗅小球的平均边数。
- 气味的偏好得分：s_o = Σ_g r_og·b_g ÷ Σ_g r_og。
- 按 s_o 分成三等份：最高的三分之一为“高偏好气味”，最低的三分之一为“低偏好气味”。准确率在各子集的测试样本上分别计算。

## 5. 预注册比较（Holm family 只含 L1、L2；L3 为等价检验）

| ID | 比较 | 通过条件 |
|---|---|---|
| L1 | 全部气味：real − `glomerulus_uniform` | Δ ≥ 1pp，CI 下界 > 0，Holm p ≤ 0.05 |
| L2 | 交互项：(real − `glomerulus_uniform`) 在高偏好气味上的差值 − 在低偏好气味上的差值 | Δ ≥ 2pp，CI 下界 > 0，Holm p ≤ 0.05 |
| L3 | 全部气味：real − `degree_preserving` | 95% CI 落在 ±1pp 之内判“等价”，否则“未确定” |

描述性报告：突触数加权编码、`er`、`pn_ncm`，以及各拓扑在高、低偏好子集上的准确率。

## 6. 解释边界

- DoOR 是多来源整合的“共识”响应，缺失值填 0 会低估部分响应；28 个嗅小球不覆盖全部输入。
- 若 L2 通过，只说明“采样偏好有利于判别那些主要驱动被过度采样嗅小球的气味”，不涉及行为层面的生态意义。
