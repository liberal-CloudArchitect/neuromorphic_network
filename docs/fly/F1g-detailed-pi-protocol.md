# F1g：通过真实输入通路驱动的路径积分

## 1. 动机与结构依据（FlyWire 783，只看结构）

F1f-v2 的阳性对照通过了，但 real 找不到“记忆 + 转动”的联合解。当时缺少的成分有：真实的角速度输入通路、视觉输入通路、PEN_a/PEN_b 偏移的检查，以及权重形式。

- PEN_a/PEN_b 最大的输入来源是 GLNO，占 19.6%。LNO 家族（GLNO、LNO1、LNO2、LNOa）共 12 个神经元，左右各 6 个，以 GABA 为主。
- EPG 的输入中约有一半来自 ER 环神经元：264 个 ER 神经元（GABA）共向 EPG 发出 38,087 个突触。

## 2. 模型

- 核心：同 F1c（EPG、EPGt、PEN_a、PEN_b、PEG、Delta7）；`relu_tanh` 激活；运行在 MPS 上；12 个类型参数，分布同 F1c-v4。
- 权重有两种，统一按核心的中位输入和 s 归一化：
  - **二值（主条件）**：突触数 ≥ 5 记为 1，符号由 `top_nt` 决定；
  - 突触数（次条件）。
- **ER 视觉输入**：
  - 用 ER→EPG 突触对 EPG 谱角度做加权环形平均，得到每个 ER 神经元的偏好角度 φ_ER；
  - 提示期（300 ms）里，与提示角度的环形距离大于 π/4 的 ER 神经元活动为 1，其余为 0；
  - 输入 = g_ER × W_ER→core · r_ER（ER 的符号由 `top_nt` 决定，几乎都是抑制），即通过去抑制形成 bump；
  - 提示结束后 ER 全部为 0（相当于“黑暗”）。
- **LNO 角速度输入**：速度期间，某一侧（`side`）的全部 LNO 家族神经元活动为 a；输入 = W_LNO→core · r_LNO，符号由 `top_nt` 决定。
- 时序：200 ms 基线 → 300 ms ER 提示 → 1,000 ms 黑暗延迟。记忆在延迟期最后 200 ms 读出，用 F1c 的模板解码；转动按 F1f 的方法，在黑暗中持续 500 ms 后开始 300 ms 的 LNO 速度驱动，读出最后 100 ms。
- 搜索：每个 seed、每种权重各抽 1,000 组候选，共 14 维：12 个类型参数，加 log₁₀ g_ER ~ U(−1, 1) 与 log₁₀ a ~ U(log₁₀ 0.05, log₁₀ 5)；候选 RNG 的 seed 为 5000 + seed，同一 seed 内所有图共享同一候选集。联合得分 = min(记忆准确率, A)。评分噪声与评估噪声的设置同 F1f-v2（评分用 950/951，评估用 200 + seed 与 201 + seed）。
- 零模型只重连核心的递归图；ER 与 LNO 的输入矩阵保持真实，落到相同的神经元 ID 上。

## 3. 阳性对照与资格检查（seed 990）

- 理想环（同 F1f-v2：48 个 EPG、左右各 48 个 ±1 偏移的 PEN、8 个 Delta7），另加：
  - 48 个理想 ER，ER_j 抑制 EPG_j，偏好角度等于 EPG_j 的角度；
  - 左、右各 1 个理想 LNO，分别抑制同侧的全部 PEN。
- 通过条件：阳性对照在二值权重下的评估记忆准确率 ≥ 0.5，且 A ≥ 0.5。否则本协议判定为 INVALID，不使用 seeds 110–119。

## 4. 预注册比较（二值权重；seeds 110–119；Holm family）

| ID | 比较 | 通过条件 |
|---|---|---|
| V1 | real A − 0 | 均值 > 0，CI 下界 > 0，Holm p ≤ 0.05 |
| V2 | real − `type_preserving` | Δ ≥ 0.2，CI 下界 > 0，Holm p ≤ 0.05 |
| V3 | real − `degree_preserving` | Δ ≥ 0.2，CI 下界 > 0，Holm p ≤ 0.05 |

描述性报告：

- 联合参数下的记忆准确率、联合得分；
- 突触数权重条件下的同样指标；
- 结构检查一：PEN_a、PEN_b 按侧别统计的“EPG 输入角 → EPG 输出角”偏移；
- 结构检查二：Delta7→EPG 权重随角度差变化的曲线；
- ER 偏好角度的调谐强度（合成向量长度）。

## 5. 解释边界

- LNO 只作为输入通路，没有自身动力学；角速度被抽象为单侧 LNO 的恒定活动，不涉及积分的定量精度。
- 只包含 ER→核心与 LNO→核心的连接；ExR 等其他外源输入不纳入。
