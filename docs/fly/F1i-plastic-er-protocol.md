# F1i：学习得到的 ER→EPG 视觉映射能否在真实 CX 中定位 bump，并支持 LNO 驱动的转动

## 1. 动机

- F1g-v2：经解剖 ER→EPG 连接直接给出的视觉提示，在任何图上都无法印刻出定位的 bump（记忆搜索最好约 0.33）。绝大多数 ER 是宽调谐的（调谐强度中位数 0.125）。
- 生物学：视觉场景到朝向的映射靠经验建立。环神经元（ER）与 EPG 同时活动时，ER→EPG 的抑制性突触被压低（Kim et al. 2019, Science；Fisher et al. 2019, Nature）。结果是：在某个朝向活跃的 ER，会抑制**除该朝向以外**的 EPG，场景重现时 bump 就被放回原位。
- 结构（FlyWire 783，二值阈值 ≥ 5）：278 个 ER 中有 219 个与 EPG 相连，连接密度 0.31（每个 ER 中位数连 16 个 EPG）。可塑性只改变这些已有突触的强度。
- F1f/F1f-v2 用 PEN 直接驱动，F1g 用 LNO 驱动但提示失败；“直接 EPG 提示 + LNO 驱动”的组合还没有检验过。

## 2. 模型（核心与 F1g-v2 相同，只用二值权重）

- 核心：EPG、EPGt、PEN_a、PEN_b、PEG、Delta7；`relu_tanh`；二值权重（≥ 5 个突触记为 1，符号来自 `top_nt`），按核心的中位输入和归一化。
- **视觉调谐（合成，与解剖无关）**：每个 ER 神经元 j 有一个偏好朝向 ψ_j ~ U(−π, π)（rng = 6000 + seed），视觉响应 f_j(θ) = exp(κ_v (cos(θ − ψ_j) − 1))，κ_v = 2。
- **可塑性（闭式稳态）**：训练时 bump 由教师信号放在每个朝向上，EPG k 的活动为 b_k(θ) = exp(κ_b (cos(θ − φ_k) − 1))，κ_b = 2.5，φ_k 为 EPG 的谱环角度。在 64 个均匀朝向上计算共激活 c_kj = mean_θ b_k(θ)·f_j(θ)，再按每个 ER 的最大值归一化，得到 Z_kj ∈ (0, 1]。学到的 ER→EPG 权重 = 解剖二值权重 × exp(−β·Z_kj)；β 参与搜索。ER 投向非 EPG 核心神经元的突触保持解剖值，不可塑。
- **三种提示方式（arm）**：
  - `learned`：视觉场景（朝向 = 提示中心）→ f_j → 学到的 ER 权重；
  - `anatomical`：同样的视觉响应，但 ER 权重不学习（只在 real 上运行，用于 I1）；
  - `direct`：提示 bin 内的 EPG 直接得到输入（F1c 的提示），不经 ER。
  - 三种方式的提示强度都乘以 g_cue。
- **LNO 角速度**：同 F1g，某一侧的 LNO 家族神经元活动为 a。
- 时序：同 F1g。200 ms 基线 → 300 ms 提示 → 1,000 ms 黑暗（ER 全部为 0），记忆读延迟期最后 200 ms；转动在黑暗 500 ms 后施加 300 ms 的 LNO 驱动，读最后 100 ms。
- **搜索**：每个 seed 抽 1,000 组候选（rng = 8000 + seed），共 15 维：12 个类型参数（分布同 F1c-v4），log₁₀ g_cue ~ U(−1, 1)，log₁₀ a ~ U(log₁₀ 0.05, log₁₀ 5)，log₁₀ β ~ U(log₁₀ 0.5, log₁₀ 20)。同一 seed 内所有图与所有 arm 共用同一候选集。评分噪声为 950/951，评估噪声为 200 + seed 与 201 + seed。
- 对每个（图，arm）选两组参数：
  - **记忆最优**：按搜索记忆得分选出，评估记忆准确率，以及解码角与提示中心之间的平均误差（锚定误差）；
  - **联合最优**：按 min(记忆, A) 选出，评估联合得分 J = min(记忆, A)。
- 零模型：`type_preserving`、`degree_preserving` 只重连核心递归图（rng = 10000 + seed，同 F1c-v4）；ER、LNO 输入矩阵、视觉调谐与教师坐标 φ 保持不变。

## 3. 阳性对照与资格检查（seed 990）

- 理想转动环（48 个 EPG，左右各 48 个 ±1 偏移的 PEN，8 个 Delta7），加上：
  - 48 个理想 ER，**全连接**到全部 EPG（视觉调谐随机，必须靠学习形成映射）；
  - 理想 LNO；
  - 全部突触数 × 5，使二值阈值不会删除任何连接（F1g 的教训）。
- 每个 arm 单独判定：联合最优参数下记忆 ≥ 0.5 且 A ≥ 0.5。`learned` 不通过时，I1、I2、I3、I5 判 INVALID；`direct` 不通过时，I4 判 INVALID。两者都不通过，则不使用正式 seeds。`anatomical` 在对照上只做描述性报告。
- 设计检查（已披露）：冻结前只在 seed 991 上运行过阳性对照，用来确认学习映射的设计可行；没有在任何真实图上运行。结果：`learned` 记忆 1.000、A +0.999；`anatomical` 记忆 0.087；`direct` 记忆 1.000、A +0.999。也就是说，在理想环上，同样的视觉输入不经学习无法定位 bump，经共激活压低学习后可以。

## 5. 解释边界

- 教师 bump 是理想化的替身，代表学习期间由自身运动维持的朝向；在本抽象中，路径积分尚未复现，所以不能让网络自己的 bump 当教师。
- 可塑性用的是“均匀朝向采样下共激活压低”的闭式稳态，而不是在线学习过程；视觉调谐是合成的 von Mises 函数，不是真实的 ER 感受野。
- 只纳入 ER→核心与 LNO→核心；ER 自身没有动力学。
- I1 通过，说明可塑性是让视觉提示可用的必要成分；I3 或 I4 通过，才说明真实接线在 LNO 驱动下表现出了转动。
