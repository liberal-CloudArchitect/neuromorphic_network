# F1n：记忆优势跟着“类型级输入组成”走，还是跟着“神经元级接线”走

## 1. 动机与描述性诊断（冻结前完成，只看结构）

F1m 显示：加活动下限后，真实 CX 拓扑的记忆优势在 FlyWire 上稳健（突触数 +0.41），在 hemibrain 上不成立（+0.025）。冻结前对两个数据集做了纯结构比较：

- **排除：hemibrain 缺少角度拓扑。** 各类型 EPG 输入与输出的角度调谐（按 EPG 谱角度加权的合成向量长度，中位数）在两个数据集上同样强：EPG 0.90/0.89 对 0.91/0.91，PEN_a 0.90/0.90 对 0.85/0.88，PEN_b 0.94/0.95 对 0.89/0.95。type_preserving 零模型在两个数据集上同样把它们破坏到约 0.2–0.4。
- **排除：权重分布形状不同。** 变异系数 1.34 对 1.25；前 10% 的边承载 43% 对 39% 的突触。
- **差异：类型级输入组成（E/I 比例）。** 在 hemibrain 中，Delta7 的抑制在每个类型的输入里占比都更高（按突触数）：

| 接收类型 | FlyWire | hemibrain |
|---|---:|---:|
| EPG | 0.11 | 0.18 |
| PEN_a | 0.06 | 0.21 |
| PEN_b | 0.20 | 0.43 |
| PEG | 0.29 | 0.48 |
| EPGt | 0.56 | 0.77 |
| Delta7 | 0.46 | 0.58 |

  二值阈值不消除这一差异（hemibrain ≥ 17 时 PEN_a 为 0.22，FlyWire ≥ 5 时为 0.04）。模型中的增益按**突触后类型**设置，会同步缩放一个神经元的全部输入，所以搜索**无法**调整兴奋与抑制的比例；输入组成是由数据固定的。这也与 hemibrain 有效候选少、延迟期活动低的现象一致。

## 2. 设计：2 × 2 组成互换（突触数权重）

- **接线来源**：FlyWire 或 hemibrain（神经元级图，包括每个类型块内部的连接方式）。
- **输入组成**：本数据集自己的，或另一个数据集的。对每个（突触前类型 → 突触后类型）块乘以同一个系数，使每个突触后类型的输入组成（`type_composition`，按行归一化）等于目标；块内部的接线不变（`match_composition`）。冻结前已核对：在 real 与 type_preserving 上，组成匹配的最大误差 ≤ 1×10⁻¹⁶。
- **图**：real 与 type_preserving（rng = 10000 + seed）。type_preserving 保留块总和，所以同一个块系数对它同样适用。
- **方法**：与 F1m 完全相同（`fly_f1m_floor.search_and_evaluate`）：活动下限（延迟期 EPG 平均活动 ≥ 0.05 且空间标准差 ≥ 0.05），1,000 组候选（rng = 11000 + seed），搜索噪声 950，评估噪声 300 + seed；每个数据集用自己 real 图的谱角度定义 8 个提示 bin。
- 优势 = real 的记忆 − type_preserving 的记忆（同一个 seed、同一个 arm）。
- 描述性：被选中状态的 bump 一致性（延迟期 EPG 群体向量长度 / 总活动）与锚定误差，有效候选比例，无下限规则下的记忆。

## 3. 阳性对照（seed 990）

理想环（突触数 × 5），按带下限的规则评估，记忆 ≥ 0.5 才算通过。设计检查：冻结前只在 seed 991 上运行过（记忆 1.000），没有在任何真实数据上运行动力学。

## 4. 预注册比较（seeds 190–199；Holm family 为 N1–N3）

| ID | 比较 | 通过条件 |
|---|---|---|
| N1 | hemibrain 接线 + FlyWire 组成：real − type_preserving | Δ ≥ 0.10，CI 下界 > 0，Holm p ≤ 0.05 |
| N2 | FlyWire 接线：优势（自己的组成）− 优势（hemibrain 组成） | Δ ≥ 0.10，同上 |
| N3 | hemibrain 接线：优势（FlyWire 组成）− 优势（自己的组成） | Δ ≥ 0.10，同上 |

解释规则（预先写定）：

- N1、N2、N3 都通过：差异主要来自**类型级输入组成**（hemibrain 中更强的 Delta7 抑制），两个数据集的神经元级接线在这一抽象中同样能支持记忆。
- N1、N3 不通过且 N2 不通过：差异主要来自**神经元级接线**，与组成无关。
- 其他组合：部分解释，按各项结果分别报告。

## 5. 解释边界

- 块级缩放改变的是突触强度的类型级比例，不改变连接本身；它回答的是“如果两个数据集的类型级 E/I 比例相同，会怎样”，而不是哪个数据集的突触计数更接近生理真实。
- 两个数据集的 E/I 差异本身可能来自生物学，也可能来自突触检测方法（例如不同递质类型的突触被检测出的比例不同）；本协议不区分这两者。
