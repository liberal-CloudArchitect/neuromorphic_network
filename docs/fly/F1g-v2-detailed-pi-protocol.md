# F1g-v2：与 F1g 相同，只修正阳性对照

## 1. 修正原因

F1g 在资格检查阶段失败（seed 990：记忆 0.087，A −0.087），正式 seeds 110–119 未被使用，F1g 判定为 INVALID。

事后诊断只针对阳性对照：理想环的突触数沿用了 F1c 的设定（Delta7 收 2 个、返 3 个突触，±2 邻居 4 个），在二值阈值（≥ 5）下全部被删掉，阳性对照因此失去了抑制与远端耦合。把阳性对照的全部突触数（含理想 ER 与 LNO）乘以 5 后，二值条件下记忆为 1.000，A 为 +0.950；突触数条件下结果不变（归一化后与原来等价）。可见 ER 去抑制提示与 LNO 抑制性速度输入这两种机制本身可行。

## 2. 唯一的修改

- 阳性对照 = 理想转动环与理想 ER/LNO 通路，**全部突触数 × 5**。
- 正式 seeds 改为 130–139（不复用 F1g 的 110–119）。
- 其余与 `F1g-detailed-pi-protocol.md` 完全一致：模型、两种权重条件（二值为主）、ER 与 LNO 通路、搜索预算、联合得分、评估噪声（200 + seed 与 201 + seed）、零模型、V1–V3 的定义与门槛，以及描述性报告。

## 3. 已有的结构结果（来自 F1g 运行，与动力学无关，可直接引用）

| 检查项 | 结果 |
|---|---|
| PEN 偏移，左侧 | PEN_a −4.9°，PEN_b −6.0°；一致性 1.00 |
| PEN 偏移，右侧 | PEN_a +2.9°，PEN_b +5.1°；一致性 1.00 |
| Delta7→EPG 按角度差（0–π，8 档）的平均突触数 | 0.07, 0.04, 0.01, 0.02, 0.11, 0.58, 2.08, 3.60 |
| ER 调谐强度 | 中位数 0.125；> 0.5 的只占 6.5%（共 278 个 ER） |

解读：

- 左右 PEN 的偏移方向相反、组内完全一致，说明转动的基础结构存在。偏移幅度只有 3–6°，可能是谱角度坐标压缩所致。
- Delta7 抑制的是相反方向的 EPG，与环形吸引子的经典结构一致。
- 大多数 ER 是宽调谐的，视觉提示的定位作用因此较弱。
