# F1k：突触标签或兴奋性谷氨酸，能否把 MBON→DAN 回路从“共模漂移”变成记忆特异的作用

## 1. 动机

F1j 显示：真实 MBON→DAN 正反馈不巩固单条记忆（J1 方向相反），而是让所有气味一起偏向趋近（J2、J3），且不依赖真实接线（J4）。原因在于 DAN 的教学信号是 compartment 级的，而 KC 编码彼此重叠，反馈驱动于是几乎不区分气味。两种可能让回路变得记忆特异的机制：

1. **KC 侧突触标签（资格迹）**：强化引起的多巴胺与 KC 活动的巧合会给该 compartment 中活跃的 KC→MBON 突触打上一个衰减的标签（类比 Rutabaga 腺苷酸环化酶的 Ca²⁺/多巴胺巧合检测与 cAMP 信号）；反馈回路引起的那部分多巴胺**只能改变带标签的突触**。驱动可以是非特异的，特异性来自标签，即“标签与捕获”。
2. **兴奋性谷氨酸**：回避 MBON 抑制自己 PAM 的 560 个互惠反馈突触里，有 505 个来自 7 个谷氨酸能 MBON。谷氨酸在果蝇中也能经兴奋性受体起作用。若按兴奋处理，回避侧的正反馈变为负反馈。

## 2. 冻结前的设计检查（已披露）

冻结前只在 seed 996（非资格、非正式）上做过一次冒烟测试（`--smoke 996`）。观察到：

- 加标签的真实回路在 `retention` 中的趋近指数为 0.089（`none` 为 0.059），偏向从 +0.067 降到 +0.007；理想正反馈加标签为 0.095；兴奋性谷氨酸回路的偏向为 −0.019（`none` 为 −0.021），趋近指数为 0.040。
- 没有再暴露时（`retention_novel`），加标签的回路同样维持了记忆（0.081）：非特异的共模驱动会刷新带标签的突触。
- 重连回路加标签后也能维持记忆（0.083），但偏向仍为 +0.071。

据此加入 K6（标签只在真实接线下消除漂移）与 K7（巩固的代价是反转变慢）。这两个假设来自 seed 996 的观察，在正式 seeds 上检验。

## 3. 任务、指标与读出

与 F1j 完全相同（`episodes`、`indices`）：40 个气味原型（20 个训练、20 个新异），获得 3 次强化，然后是 `retention`、`retention_novel` 或 `reversal`，最后用不学习的探针测量。指标包括以新异气味为参照的趋近与厌恶指数（`app`、`av`）、偏向（`bias`）以及获得后的指数（`*_acq`）。

## 4. 标签规则

设 DAN 活动为 dan = relu(奖惩 + g_fb·反馈)。其中强化部分 = min(dan, 奖惩)，反馈部分 = dan − 强化部分。可塑性为：

W ← W − η·[(强化部分 @ T)·z + (反馈部分 @ T)·(z ⊙ 标签)] + ρ·(C − W)

更新之后，标签 ← min(1, λ·标签 + (强化部分 @ T)·z)。T 为 DAN→MBON 教学矩阵（按 MBON 归一化），λ 为每个试次的标签保留率。

## 5. 变体

| 变体 | 反馈矩阵与符号 | 标签 |
|---|---|---|
| `none` | 无 | — |
| `replay_oracle` | 无；再暴露时按获得效价重新强化（任务阳性对照） | — |
| `ideal` | 对立的理想 RPE（描述性） | — |
| `loop_real` | 真实反馈；GABA 与谷氨酸为抑制 | 无 |
| `loop_real_tag` | 同上 | 有 |
| `loop_rewired_tag` | 保度重连的反馈（rng = 7000 + seed） | 有 |
| `loop_glu` | 真实反馈；**只有 GABA 为抑制，谷氨酸与乙酰胆碱为兴奋** | 无 |
| `loop_glu_tag` | 同上 | 有 |
| `loop_positive_tag` | 每个 MBON 只抑制性地反馈给教导它的 DAN（机制阳性对照） | 有 |

## 6. 参数：全部变体共用同一网格

η ∈ {0.1, 0.3, 1.0} × ρ ∈ {0.001, 0.003} × g_fb ∈ {1, 3} × λ ∈ {0.99, 0.999}，共 24 个点；g = 1。不使用某个参数的变体按同样 24 个点计算。每个 seed 的主指标 = 24 个网格点的平均。

## 7. 资格检查（seeds 990–994）

- **任务门**：`retention` 中，`replay_oracle` − `none` 的趋近指数 ≥ 0.02。不通过则整个协议 INVALID。
- **机制门**：`retention` 中，`loop_positive_tag` − `none` 的趋近指数 ≥ 0.02。不通过则 K1、K3 判 INVALID（说明标签机制在本模型中根本不能产生巩固）。

## 9. 解释边界

- 标签是抽象的突触级状态变量，不模拟 cAMP/PKA 动力学；“KC 侧”指它按 compartment 和 KC 分开存储。
- DAN 没有自发活动，relu 把负的驱动截在 0：兴奋性谷氨酸只在强化期间起减法作用，无强化时不会产生“低于基线”的信号。这意味着本协议检验不到经 DAN 活动下降实现的消退。
- 递质与受体的符号是假设，真实 MBON→DAN 突触的受体组成未知。
