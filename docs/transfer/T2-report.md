# T2 结果：局部关联读出几乎消除了类增量遗忘，三个组成部分都有因果作用；与回放打平，但没能在 2pp 内证明非劣

本报告属于 T track 的探索层，不构成任何 Gate 证据。协议在运行之前已冻结并提交（`5ef3980`）；冻结前在非正式 seed 999 上做过两次设计检查，改动已在协议第 8 节披露（编码器改为固定随机、按码可靠性规则把 σ 定为 0.5、扩展改为 F1a 尺度、扩大 EWC 的 λ 网格）。正式运行耗时 4,788 s（前约 80 分钟只有 2 个进程，因为 T1c 同时占用 8 个核）。

## 2. 裁决与解释（协议 6.1）

- **迁移有效（H1、H2）**：主网络模块上的局部关联读出把类增量的最终准确率从 0.205 提高到 0.877，遗忘从 0.992 降到 0.048，远超主线 0.02 的遗忘判据。所有 10 个 seed 方向一致（+0.61 至 +0.71）。
- **三个组成部分都有因果作用（H3–H5）**：
  - 学习规则（H3）：同一稀疏码改用 SGD 读出，最终只有 0.528，并且明显偏向最近的任务（任务 1 只剩 0.10）。
  - 表示冻结（H4）：编码器在每个任务上继续用 SGD 学习时，关联权重写入时的码与测试时的码不再一致，最终只有 0.328。
  - 稀疏扩展（H5）：同一固定编码器上的类均值最近邻为 0.714，比关联读出低 16pp；多峰类别下类均值把不相关的原型混在一起，与 F1a-v4 的 +17pp 一致。
- **与回放打平（H6、H8）**：二者的最终准确率几乎相同（0.877 对 0.879），CI 为 [−0.023, +0.018]。既不优于回放，非劣性的下界也比 −0.02 低 0.3pp，按协议是 NOT_NON_INFERIOR。逐 seed 差值在 −0.058 与 +0.051 之间，各有 5 个 seed 偏向一方。
- **EWC 在单头类增量下几乎无效（H7）**：最佳 λ 为 1e4–1e5（1e6 从未被选中），最终只有 0.266。这与已知文献一致（单头类增量中 EWC 无法保护旧类的输出）。

## 3. 两种防遗忘方式的行为不同（预注册描述）

analysis 上的平均准确率矩阵（行：学完第 t 个任务后；列：各任务）：

| | 任务 1 | 任务 2 | 任务 3 | 任务 4 | 任务 5 |
|---|---:|---:|---:|---:|---:|
| `mod_assoc` 学完任务 1 | 0.95 | | | | |
| 学完任务 5 | 0.87 | 0.88 | 0.85 | 0.89 | 0.88 |
| `gru_replay` 学完任务 1 | 1.00 | | | | |
| 学完任务 5 | 0.75 | 0.84 | 0.86 | 0.93 | 1.00 |

- 关联读出对每个任务都“学得不那么满”（刚学完时约 0.88–0.95，受稀疏码质量限制），但之后几乎不掉，最终五个任务一样好：它的遗忘只来自新类加入后的竞争，不来自旧权重被改写（旧类的权重行从不改变，单元测试核对）。
- 回放对新任务学得很满（1.00），但越早的任务掉得越多（任务 1 掉到 0.75），呈明显的近因偏向。
- 二者的平均恰好相同，但适用场景不同：关联读出不存原始样本、只做一遍累加（每个 seed 约 1 s，梯度方法约 40 s），且不需要梯度；回放需要存储并反复训练旧样本。

## 4. 其他描述性结果

- 结构对照：`mod_sgd`（0.206）与 `gru_sgd`（0.205）相同：模块化网络本身在 SGD 下同样灾难性遗忘，收益完全来自读出的学习规则与固定的输入映射。
- 任务 1 预训练再冻结（`abl_pretrained`，0.458）：不遗忘（0.014），但新类只有约 0.31–0.34。在少数类上训练出的表示不能推广到新类；这是设计检查中发现、协议中改用固定随机编码器的原因，正式结果证实了这一点。
- 选中的超参数：`gru_replay` 7/10 个 seed 选 lr = 3e-4；`gru_ewc` 选 (1e-3, 1e5) 4 次、(3e-4, 1e4) 6 次。

## 5. 结论

1. **F1a 的原理迁到主网络模块后依然成立**：固定的输入映射 + 稀疏扩展 + “只增强活跃单元 → 正确类”的局部关联读出，几乎消除了类增量遗忘（遗忘 0.99 → 0.05），而且学习规则、表示冻结与稀疏扩展三者缺一不可。
2. **它与回放打平，而不需要存储旧样本或梯度训练**；但在 2pp 的界值内未能证明非劣（下界 −2.3pp）。两者的误差结构互补：关联读出均匀但每个任务的上限较低，回放对新任务好、对旧任务差。
3. **限制在表示上**：编码器必须固定（或者至少不能在后续任务上用 SGD 继续学习）；在少数类上预训练的编码器反而有害。如何获得既能学习、又不破坏旧码的表示，是把这一原理放进完整网络前需要回答的问题。

## 6. 解释边界

- 合成的多峰模式任务，σ = 0.5 处于码可靠的低噪声区（同原型 Jaccard ≈ 0.41）；在码不可靠的高噪声区优势预期会消失（F1a-v3）。
- 参数按“学到的参数”匹配；固定的随机编码器（18,880）与扩展连接（7,680 个二值连接）不计入。回放存储的 200 个原始样本（19,200 个数）与关联权重（25,600 个数）量级相当，但并非严格匹配。
- 只有一种类增量顺序与 5 × 4 的任务结构；没有检验更多任务或更多类时的容量极限。

## 7. 下一步候选（各需新协议）

- 关联读出 + 回放的组合（二者误差结构互补），或用少量回放只校准关联读出。
- 让表示可学习但不破坏旧码：例如只在第一个任务前用无关数据预训练，或对编码器使用 F1k 式的资格标签巩固（T4）。
- 把关联读出用作主网络情景记忆的编码（CR-014 的 T5：二值稀疏扩展），在多峰类别检索上与原型、1-NN 比较。
