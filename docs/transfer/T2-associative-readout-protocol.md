# T2：把“只增强活跃单元 → 正确类的突触、其余不动”的读出迁到主网络，能否阻止类增量遗忘

## 1. 依据

- F1a（`docs/fly/F1a-report.md`，四轮预注册）：只增强“活跃 KC → 正确类”突触、其余突触冻结的局部关联读出，比 SGD 与感知机读出高 30–43pp，遗忘从 0.54–0.90 降到约 0.15（C1、E3、E4）；稀疏二值扩展在多峰类别、码可靠（同峰 Jaccard ≥ 约 0.4）时比类均值原型高约 17pp（F1a-v4 G1–G3），码不可靠时优势消失（F1a-v3）。F1a 中 PN→KC 映射是固定的随机连接，从不训练。
- 主线：读出/动作头（`action_selector.v1`）用 SGD 训练；P3/P4 的顺序训练遗忘判据为每个任务“历史最佳 analysis 分数 − 最终分数”，要求基线 − 模块化 ≥ 0.02。
- T2 检验：在主网络的模块（task adapter → `sensory_encoder.v1`）之上，用固定的随机编码 + 稀疏扩展 + 局部关联读出代替 SGD 读出，能否在类增量学习中阻止遗忘；并逐项拆开学习规则、表示冻结与稀疏扩展的作用。

## 2. 任务：`incremental-patterns-v1`（`neuromorphic.transfer.incremental_patterns`）

- 一个 *world* 有 5 个任务 × 4 个类 = 20 个类；每个类是 3 个互不相关的稀疏原型的并集（32 个输入通道，每个通道以 0.3 的概率激活，激活值为 lognormal(0, 0.5)），所以类均值会把不相关的模式混在一起（多峰类别）。
- 每个样本：某个类的某个原型连续出现 3 帧，每帧加独立的高斯噪声（σ，见下），然后是一个 query 步（标志位为 1），query 步的目标是类别。输入 33 维。
- **类增量**：5 个任务依次学习，每个任务只给出该任务 4 个类的训练样本；测试时没有任务标签，在“目前见过的所有类”中作答。
- world 由 model seed 决定（每个 seed 一套新的原型）；每个 split 的样本噪声由独立的 split seeds 生成：train 61101、validation 62201、test 63301、analysis 65501（OOD 不使用）。每个原型 train 100、validation 20、test 40、analysis 20 个样本（每个 split 分别 6,000、1,200、2,400、1,200）。
- **σ = 0.5**，由第 8 节的码可靠性规则确定（不看任何模型的成绩）。此时（world 991/996/999，validation）：Bayes 最优 1.000，原始输入（帧平均）的 1-NN 1.000，类均值（NCM）0.785–0.816。
- **上限**：已知原型与 σ 的 Bayes 最优分类器（帧平均是充分统计量，可精确计算）；以及同一 GRU 在全部任务上联合（非顺序）训练的结果 `gru_joint`（描述性参照）。

## 3. 模型

| 模型 | 表示 | 读出 / 防遗忘方法 | 学习的参数（不含固定随机部分） |
|---|---|---|---:|
| `gru_sgd` | adapter (33→56) → GRU(56) | `action_selector.v1` 头（20 类），顺序 SGD（主基线） | 25,500 |
| `gru_replay` | 同上 | 同上 + 回放：每个旧类存 10 个训练样本，此后每个 batch 一半来自回放 | 25,500（另存 200 个样本） |
| `gru_ewc` | 同上 | 同上 + online EWC（每个任务后用 200 个样本估计对角 Fisher 并累加） | 25,500 |
| `mod_sgd` | adapter (33→64) → `sensory_encoder.v1`，对 3 帧取平均 | `action_selector.v1` 头，顺序 SGD（结构对照） | 24,468 |
| **`mod_assoc`** | 同上，**编码器固定在随机初始化，从不训练** | 稀疏扩展（1,280 个单元，每个单元对 6 个随机特征求和，k-WTA 保留 64 个即 5%，二值）+ 局部关联读出：每个训练样本 W[c] += code，其余不变；作答 argmax_c code·W[c] | 25,600 |
| `abl_sgdread` | 同 `mod_assoc` | 同一稀疏码，读出改为 SGD 训练的线性层（学习规则消融） | 25,620 |
| `abl_plastic` | 编码器在每个任务上都经 `action_selector.v1` 辅助头用 SGD 训练 | 同 `mod_assoc` 的关联读出，写入时用当前编码器（表示冻结的消融） | 50,068 |
| `abl_ncm` | 同 `mod_assoc` | 稠密特征上的类均值最近邻（稀疏扩展的消融） | 1,280 |
| `abl_pretrained` | 编码器在任务 1 上训练后冻结 | 同 `mod_assoc`（描述性：任务 1 预训练的表示能否推广到新类） | 50,068 |
| `gru_joint` | 同 `gru_sgd` | 全部任务混合训练（描述性上限参照，不参与比较） | 25,500 |

- 参数量按“学习的参数”匹配：`mod_assoc` 的 1,280 × 20 = 25,600 个关联权重与 GRU 的 25,500 个参数相当；固定不变的随机编码器（18,880）与随机扩展连接（1,280 × 6 个二值连接）不计入，如同 F1a 中固定的 PN→KC 映射。GRU 隐层取 56（而不是 64），使其与模块化网络（24,468）在 ±6% 内匹配。
- 稀疏扩展的比例（64 → 1,280，即 20 倍；5% 激活；每单元 6 个输入）取自 F1a 的 PN→KC 尺度。

## 4. 训练与选择

- 每个任务 1,000 次更新，batch 64（共 5,000 次）；AdamW，weight decay 1e-2，梯度裁剪 1.0；只在当前已见过的类上计算 cross-entropy。`gru_joint` 用 5,000 次更新、全部 20 类混合。
- 关联读出与类均值在每个任务的全部训练样本上各累积一遍；`mod_assoc`、`abl_ncm` 没有任何梯度训练。
- 超参数网格：所有梯度训练部分的学习率 {1e-3, 3e-4}（同 T1）；`gru_ewc` 另有 λ ∈ {1e2, 1e3, 1e4, 1e5, 1e6}。每个（模型，seed）取**最终 validation 准确率**（5 个任务结束后，20 类）最高的组合。没有逐步的检查点选择（顺序学习只看最终模型）。
- **model seeds 801–810**（新；同时决定 world）。同一 seed 下各模型面对同一组原型与同一随机编码器初始化。
- test 只在最终模型上评估一次；analysis 只用于记录每个任务结束后各已学任务的准确率（遗忘曲线），不参与选择。
- 脚本：`scripts/transfer_t2_associative.py`；结果写入 `artifacts/transfer/t2_report.json`（git-ignored）。

## 5. 指标

- **最终准确率**（主指标）：5 个任务都学完后，test 上 20 类的平均准确率（每个任务的准确率取平均）；
- **遗忘**（主线定义）：analysis split 上，对前 4 个任务分别取“该任务学完之后历次评估中的最高准确率 − 最终准确率”，再平均。

## 6. 预注册比较

Holm family 为 H1–H7（superiority）；H8 为非劣性检验（界值 0.02）。

| ID | 指标 | 比较 | 通过条件 |
|---|---|---|---|
| H1 | test 最终准确率 | `mod_assoc` − `gru_sgd`（相对主基线） | Δ ≥ 0.10，95% CI 下界 > 0，Holm p ≤ 0.05 |
| H2 | analysis 遗忘 | `gru_sgd` − `mod_assoc`（主线遗忘判据） | Δ ≥ 0.02，同上 |
| H3 | test 最终准确率 | `mod_assoc` − `abl_sgdread`（学习规则） | Δ ≥ 0.05，同上 |
| H4 | test 最终准确率 | `mod_assoc` − `abl_plastic`（表示冻结） | Δ ≥ 0.05，同上 |
| H5 | test 最终准确率 | `mod_assoc` − `abl_ncm`（稀疏扩展，多峰类别） | Δ ≥ 0.03，同上 |
| H6 | test 最终准确率 | `mod_assoc` − `gru_replay`（相对回放） | Δ ≥ 0.02，同上 |
| H7 | test 最终准确率 | `mod_assoc` − `gru_ewc`（相对 EWC） | Δ ≥ 0.02，同上 |
| H8 | test 最终准确率 | `mod_assoc` − `gru_replay`（non-inferiority） | 95% CI 下界 > −0.02 |

统计：每个 seed 的配对差，10,000 次百分位 bootstrap（RNG 20260715），`neuromorphic.transfer.statistics.paired_contrasts`。

### 6.1 解释

- H1、H2 回答“迁移是否有效”（主线遗忘判据）；H3–H5 回答“是哪一部分起作用”；H6–H8 回答“相对常见防遗忘方法的位置”。
- 若 H1、H2 成立但 H6 与 H8 都不成立，说明局部关联读出能防遗忘，但不如存储原始样本的回放。

## 7. 描述性分析（预注册，不做裁决）

1. 每个模型的 analysis 准确率矩阵（任务 t 学完后各任务的准确率）与最终的逐任务准确率。
2. 参照水平：Bayes 最优、原始输入 1-NN 与 NCM（test）、`gru_joint`。
3. 结构对照 `mod_sgd` − `gru_sgd`；任务 1 预训练的影响 `abl_pretrained` − `mod_assoc`。
4. 选中的学习率与 λ。

## 8. 冻结前的设计检查（已披露）

第 6 节的比较与阈值在设计检查之前已写入脚本。设计检查只在非正式 seed/world 999 上运行（`--pilot`），只用 train/validation（遗忘曲线改在 validation 上记录），没有访问 test 与 analysis；σ 的标定另用了非正式 world 991、996、999 的 train/validation 数据，不涉及任何模型。

1. **初版**（σ = 0.9；`mod_assoc` 的编码器先在任务 1 上训练再冻结；扩展 320 个单元、16 个激活；EWC λ ∈ {10, 100, 1000}）。validation 最终准确率：`gru_sgd` 0.207，`gru_replay` 0.591，`gru_ewc` 0.216，`mod_sgd` 0.211，`mod_assoc` 0.315（遗忘 0.009），`abl_sgdread` 0.199，`abl_plastic` 0.285，`abl_ncm` 0.433，固定随机编码器版本 0.618，`gru_joint` 0.931。发现三个问题：
   - 在任务 1 上训练后冻结的编码器几乎不遗忘，但新类学不会（任务 2–5 只有 0.05–0.23）：任务 1 的表示不能推广到新类。F1a 的“冻结”指其他类的读出突触不变，表示本身是固定的随机映射。因此主模型改为**固定随机编码器**，原设计降为描述性的 `abl_pretrained`。
   - σ = 0.9 时同一原型的稀疏码 Jaccard 重叠只有 0.21，处在 F1a-v3 已显示“稀疏码优势消失”的不可靠区。改为按 F1 总结中的诊断量定 σ：在 {0.3, 0.4, …, 0.9} 中取“固定随机编码 + 扩展后，同原型 Jaccard 在 world 991/996/999 上的平均值 ≥ 0.4”的最大 σ。各 σ 的平均 Jaccard：0.3 → 0.57，0.4 → 0.48，**0.5 → 0.41**，0.6 → 0.35，0.7 → 0.30，因此 σ = 0.5。这一步只用任务数据与固定的随机编码，不看任何模型的成绩。
   - 扩展规模改为 F1a 的 PN→KC 尺度（20 倍、5%），即 1,280 个单元、64 个激活；此时关联权重 25,600 个，与 GRU 的参数量相当。
   - EWC 在所有 λ 下都没有减轻遗忘（遗忘 0.95–0.98），阳性对照不成立，因此把 λ 网格扩大到 {1e2, 1e3, 1e4, 1e5}。回放通过阳性对照（0.591 对 0.207）。
2. **改后**（同一 seed）：`gru_sgd` 0.239，`gru_replay` 0.905，`gru_ewc` 0.313（λ = 1e5、lr = 1e-3；遗忘 0.86，相对 SGD 有小幅减轻），`mod_sgd` 0.208，`mod_assoc` 0.931（遗忘 0.039），`abl_sgdread` 0.641，`abl_plastic` 0.395，`abl_ncm` 0.691，`abl_pretrained` 0.412，`gru_joint` 0.999。EWC 的最佳 λ 落在网格边缘，所以再加入 1e6（只增加基线的选项，没有重新检查）。单个 seed 的这些数值不构成结论。
3. 耗时：梯度训练的作业约 40 s，关联读出约 1 s；正式运行 10 个 seed × 30 个作业，8 个进程，预计约 30 分钟。

## 9. 解释边界

- 这是 T track 的探索性检验，不构成任何 Gate 证据；不修改 P1–P5 的模块、协议或锁。`selector_head` 只新增了类别数参数（默认值保持 T1/T1b/T1c 的行为）。
- `mod_assoc` 的编码器是主网络模块，但固定在随机初始化：检验的是“固定输入映射 + 局部关联读出”，不是“学到的表示 + 局部关联读出”；后者由 `abl_plastic` 与 `abl_pretrained` 描述。
- 任务是合成的多峰模式，处在码可靠的低噪声区；结论不外推到码不可靠的高噪声区（F1a-v3 已显示那里优势消失）。
- 回放的存储（200 个原始样本）与关联权重的存储（25,600 个数）不是严格匹配的。
